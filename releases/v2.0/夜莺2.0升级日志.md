# 夜莺 2.0 升级日志

2026-09-16 发布。相对 1.0 的主要变化按"字 → 词 → 简词 → 扩展字 → 输入法功能"的顺序列出；每一步的裁定与数据都在仓库 `work/夜莺2.0/` 对应编号目录里。

## 字根与单字

- 字根重新整理为 130 组、404 根形（删利根，利字族拆禾＋刂；正归止组）；键位由退火与人工裁定共同决定。
- 单字表以一张"纯单字表"为真身，可从退火起点加逐批人工裁定重放出来（`83_单字表重放`）。8105 通用规范汉字通过 13 项核验。
- 简码归属按"单字独立成词的频率"人工裁定；二三简兼占与让位、容错码按《码表概念与规则》执行。容错码与无理码只作附加，不参与规则判定。
- 有简码的字在全码位让给二字词（字词让位），三字及以上的词不让；人工指定 120 处码位优先。

## 词

- 普通词改为"各家共识"：鲸凉鹤、简单鹤、魔然、虎码四家词库至少三家收录才进表，115747 条；补入 937 条共识词，读音以单字表为准。
- 词与词的先后由简单鹤、魔然、虎码三家投票（一家至少收两个词才有票），无多数的保持鲸凉鹤原序；含"一"的码位按语料词频排。
- 叠词改规则码、飞键还原、`o` 前缀特设短语裁定、功能字拼词清理、错码改回与补读音，均逐条登记。

## 简词

- 二字简词 952 条（首字首码＋次字首码，人工项优先，其余按词频，每位封顶）。
- 三字词一律走三码（三字首码），17282 条；简码位上字在前、简词在后，字的简码不让位。

## 扩展字

- 加入新华字典比 8105 多出的 7391 个字（含繁体旧字形 655），拆分从 1.0 扩展字表按 2.0 规则继承，7 个无拆分字人工裁定。
- 扩展字全码排在同码位现有字词之后；语料出现过且三简位没有字的给三简（147 字）。
- 最终表 155139 条、109127 个码位。

## 输入法与工具

- 全平台导出：普通字词表（有/无简词、码前）、手心模块化挂接、搜狗挂接/五笔、冰凌、Bime、Rime 轻量版、主力版与手机版（轻量版 + 万象语法模型，供同文/仓输入法），均含扩展字与 40 条快符。
- Rime 新增：Ctrl+数字 钉选/加词（码表候选钉为该码首选，记在用户目录 `yeying20_pin.txt`；整句或联想出来的词则按夜莺词规则加进 `yeying20_words.txt`）；二字自动造词；Ctrl+Enter 主动造词不限长度（`yeying20_words.txt`，Shift+Delete 可删）。码表候选不随使用频率乱序。"简词进整句"做成开关，默认关（整句默认只用单字与四码词）。
- 啾啾工具箱：拆分查询、部件反查、字根练习、字根图/表、完整拆分表合为一个单文件；15496 字全部可查；练习例字补齐、两列显示。

## 2026-09-17 Rime 主力版换基座：「夜莺主力」

- **声明：新主力版的主体是魔虎（rime-mohu，作者 晴，https://github.com/fcxxxz/rime-mohu ，GPL v3），夜莺只换了数据。** 主力版改为建在魔虎之上：码表、词库、拆分仍是夜莺的，整句引擎、新版 V5 模型和全部功能（置顶、加词、候选管理、语义重排、拆分与拼音提示、皮肤编辑器、同步助手等）用魔虎的。方案选单里叫「夜莺主力」，方案与文件都用 yeying 名字（`yeying_flypy`），可以和魔虎原版装在同一个用户目录，互不覆盖；每个改名文件开头注明了它在魔虎里的原名。
- 一到四码严格按夜莺码表次序；`` ` ``双拼、`~`全拼反查和 F2 保留；不带虎码反查、皮肤编辑器、同步助手；"简词进整句"改为部署选项（默认关，见包内说明）。旧主力版的 Ctrl+数字钉选与自动造词不再提供，改用魔虎自带的置顶与加词；轻量版、手机版不变。
- 发布包本地文件改用中文名；GitHub Release 上文件名不变（官网链接不变），中文写在附件显示名里。
