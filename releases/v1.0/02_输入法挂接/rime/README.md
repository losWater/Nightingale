# 夜莺 Rime 1.0 当前发布包

请使用「发布包」目录中的最新压缩包：

- main-f2：主力模型包，同时提供轻量和形码模式。
- light-f2：不含模型，提供轻量和形码模式。

本次新增拆分反查：输入 ~ 或反引号，再输入全拼或小鹤双拼，如 ~han / ~hj，即可查看拆分及编码。三个方案均支持。

当前面向 Windows x64 小狼毫；Mac、手机尚未适配验证。导入与方案设置见包内《使用说明》。旁边的 yeying 目录是此前移入的旧参考包，请不要与新包混装。

输入两位双拼或三码后按 F2，可查询当前读音的全部核心字、拆分与编码，支持翻页；再次按 F2 返回普通候选，Esc取消。请优先使用文件名包含 f2 的最新包，旧 lookup 包保留供回退。

开启后继续输入或退格会按当前编码持续筛选（例如 yc → F2 → b，筛选 ycb）；选字上屏后退出，再按 F2 保留当前编码恢复普通模式。
