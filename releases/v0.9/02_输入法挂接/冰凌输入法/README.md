# 冰凌输入法挂接

`夜莺码v0.9冰凌词库.txt` 为冰凌输入法可导入的夜莺码词库（UTF-16 LE + CRLF），
通过「冰凌输入法设置 → 词库管理 → 导入」使用。

内容与搜狗挂接字词版同源：单字、普通词、简词与 39 条快符，并额外收入扩展字。
冰凌无显式候选位，同码候选顺序由词频降序还原主表候选序（常规条目 9999 起递减，
扩展字统一压至低频 11，排在常规候选之后）；主表中的手心宏命令词（`$ddcmd`、`#$(`）
不适用于冰凌，已排除。

词库声明夜莺构词规则（PhraseRule=3），用户自造新词时冰凌按下列规则自动编码：

```text
pa2=w11w12w21w22   二字词：两字各取前两码（双拼＋双拼）
pa3=w11w21w31      三字词：三字各取第一码
pe4=w11w21w31r11   四字及以上：前三字第一码＋末字第一码
```

重建入口：`python .\pipelines\v09\rebuild.py`（内部调用
`work/夜莺0.85/scripts/build_v085_bingling_table.py`）。

`冰虎词库3.0.txt` 及其说明为格式参考样例，非夜莺发布物。
