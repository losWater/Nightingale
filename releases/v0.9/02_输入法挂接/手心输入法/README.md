# 夜莺码 0.9 手心输入法文件

- `夜莺码v0.9电脑手心挂接.txt`：由正式挂接字词版生成，加入18770个扩展字、62468条夜莺简词及当前 `symbo.txt` 的40条快符，共211047条（2026-09-02起四码普通词采用简单鹤词库内容与词序，见 ADR-0003）；格式为 `编码=候选序号,字词`。
- `夜莺码v0.9电脑手心无二字词版.txt`：写入单字、18770个扩展字、夜莺简词和40条快符，但不写普通全码二字词；单字候选序号继承正式挂接字词版，省略的普通词语仍占据原候选位，共94848条。
- `夜莺码v0.9电脑手心辅助码.txt`：只取正式单字版中非扩展字的四码条目，截取末两位作为形码，格式为 `字=辅助码`。扩展字只参与全码挂接，不加入辅助码，辅助码仍为原来的8105个单字。
- `夜莺码v0.9电脑手心辅助码_Unicode.txt`：内容相同，采用手心提示所称的 Windows Unicode（UTF-16 LE BOM）编码，用于测试扩展区字符导入。

辅助码直接取自最终正式单字码，因此包含正式表中的无理码、容错码和人工调整。完全相同的“字＋辅助码”会去重；同一字有多个辅助码时，用空格合并在同一行，例如 `字=码1 码2`。

快符沿用 `symbo.txt` 指定的候选位置，生成时会检查它们没有覆盖正式字词。

当前挂接表使用第一批多音词校正版综合字词表生成。该批包含 302 条经 SUBTLEX 唯一整词读音支持、词频不低于 10 且排除大写专名的纠错；完整建议与应用审计位于 `work/夜莺0.86/06_0.85多音词排查_0006`。例如“重新”由误码 `vsxb` 改为 `isxb` 首选，“宠信”顺延为第二候选。

普通挂接表、无二字词版和辅助码表为 UTF-8 无 BOM；`_Unicode` 辅助码表为 UTF-16 LE BOM。挂接表使用 LF 换行，辅助码表使用 CRLF 换行。
