# 夜莺发布流程

## 平时维护（每改一条）

1. 改数据：拆分 `data/baseline/splits.json`、简码 `data/inputs/手动调整.json`、字词顺序 `data/inputs/词序调整.json` 等。
2. `.venv/bin/python build/rebuild_table.py`：重出单字表，列出码变化，门禁只作参考。
3. `.venv/bin/python release/update_local_rime.py`：字词表、五个方案装进本机 Rime（约 40 秒）。
4. 在 `release/更新日志/夜莺<版本>.md` 记一条。

## 发新版

1. 改 `release/版本.json`：`版本`、`上一版`；需要时改 `升级说明`。
2. 更新日志写好：`release/更新日志/夜莺<版本>.md`（第一行 `# 夜莺 X.Y 更新日志`，“草稿”那行发布时会自动去掉，日期自动写上）。
3. `.venv/bin/python release/publish.py`：本地生成全部附件和官网预览，放在 `~/Downloads/夜莺<版本>_发布附件/`，不公开任何东西。先看一遍官网预览。
4. 作者确认后：`.venv/bin/python release/publish.py --publish`：
   更新日志定稿 → Yozakura 打标签并同步到夜莺仓库 3.x 分支 → 建发布页、上传附件 → 触发 Windows 工作流并等它完成
   → 发布页补上 Windows 链接 → 官网按发布页实际附件重新生成并上线 → 逐个检查下载链接。

版本号、日期、文件名都不写在脚本里：统一从 `release/版本.json` 经 `release/config.py` 读取。
