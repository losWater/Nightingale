# 夜莺 3.1 更新日志

2026-10-15

3.1 是 3.0 发布后根据作者实打和群友反馈做的一次整理：新增两个归并字根，修正几处拆分，调整一批常用字的简码和词序，加了二字词的 ü 容错码；输入法方面，Rime 包解压即用，形码版可以加词。字根键位没有变。

## 拆分

- **新增字根“出”，并入山组（H 键）**：原来拆成“凵 ＋ 山”的 38 个字改拆为出，如 拙 = 扌 ＋ 出、础 = 石 ＋ 出、屈 = 尸 ＋ 出。变码 5 字：出 iurh→iuhh、祟 svrt→svht、粜 tnrz→tnhz（失去三简）、糶、䢺。
- **睾的上部归入皿组（E 键）**：原来拆成“丿 ＋ 罒”，现在作为“睾字头”与皿、罒、血同组。睾 gcfu→gceu（失去三简，gcf 给了诰）。
- **冒字头（冃）按扁日“曰”拆**：冒、帽、瑁、冕、勖、冔、毷、媢、蝐、艒、赗、焨 共 12 字，如 冒 = 曰 ＋ 目、冕 = 曰 ＋ 免。
  - 变码：冒 mcrb→mcbb，三简 mcr→mcb；冕 mmrs→mmbs（失去三简）；勖 xuri→xubi（失去三简）；冔 xurc→xubc；毷 mcrg→mcbg。
  - 连带：昴让出三简 mcb（只剩 mcbi）；瑁得三简 mcr；顼得三简 xur。
- **彧按字形拆为 弋 ＋ 口 ＋ 彡**（原拆 戈＋口＋一＋丿＋丿），码不变 yuef。
- 现为 129 组字根、408 个根形。

## 简码

- **出、处、厨、吃**：一简 i 由“吃”改为“出”，二简 iu 由“出”改为“处”，三简 iuq 给“厨”（原来只有四码）；吃改用三简 iit（嗤只留全码 iitm）。
- **只、知、智**：二简 vi 给“只”（单用很多，原来的 vit 不好按）；知改用三简 vih；智只留全码 vihb。vihv 上“智慧”排第一、“只会”第二。
- **倒、导**：dck 还给“倒”（同 2.5，原来倒只能打四码 dckg）；导改打全码 dcko（首选）。
- **激、浅、附**：jia 给“激”（济改打全码 jian）；qma 给“浅”（同 2.5，潜改打全码 qmab）；fuy 给“附”（夫改打全码 fuyy，仍排第一）。
- **煮 vul**（朱改打全码 vull）、**伸 ufk**（什改打全码 ufkc、uikc）、**右 yzc**（友改打全码 yzcq）、**搓 coo**（措改打全码 coob）、**幕 muf**（慕改打全码 mufv）、**景 jkb**（睛改打全码 jkbz）。

## 字词

- **ü 单字码字在前**：jv 剧、xv 绪，以及 jvb 居、jvr 巨、jvo 狙、yvz 予、yvl 欲、yvo 羽、yvc 郁，是方便打字的正式码（如居的全码 jubt 不好按），一律单字排第一（3.0 里这些码排在词后）。
- **二字词的 ü 容错码**：词频前 20000 的二字词，第一个字是 ju、qu、xu 的可以写成 jv、qv、xv，第二个字是 ju 的可以写成 jv，原码照常可用。如 居然 jurj/jvrj、区域 quyu/qvyu、根据 gfju/gfjv。共 250 个新码；新码上容错词排第一，原有的长词让位。
- **三码位让给特别常用的简词**：三码位仍然是字在前，但简词的词频超过字频 1000 倍时简词排第一。共 33 处，原来排第一的都是几乎不用的字，如 nag 哪个、jsu 就算是、dgr 打工人、mgx 没关系、vfb 支付宝、hzm 孩子们、npy 女朋友、kyu 可以说。
- **词序按作者实打调整**（33 个码位）：如 jiji 积极、lmxi 练习、tsyi 同意、vfui 真实、duzi 独自、qmli 潜力、guge 谷歌、gowh 过往、jkvy 精准、ourj 偶然、dt 点头、yeyk 夜莺。
- **新增词**：催更、等我、当我、幻都、出价、就好、拿钱、小岛、渔夫。
- **脯（果脯的 fǔ）不再让给长词**：fuzw 上脯排在“丰收在望”前面。

## 输入法

- **解压即用**：Rime 包直接带好 default.custom.yaml，解压到用户文件夹、点“重新部署”就能用，不用再改名或合并配置。V5、形码、单字三个方案都已列好，装几个包、先后顺序都不影响。注意：这会替换用户文件夹里原有的 default.custom.yaml，如果你还用着别的方案，部署后要把它们加回方案列表。
- **形码版加词（录词）**：按 Ctrl+Enter 开始录词，照常逐字打出，再按 Ctrl+Enter 结束，录下的字按夜莺词规则存为词（二字 AaAbBaBb、三字 AaBaCa、四字以上 AaBaCaZa）。录词时第一个候选后面显示〔录词：…〕，没有输入时按 Esc 取消；造的词带〔造〕，选中后 Shift+Delete 删除。形码版的词表独立，与 V5 版的造词互不影响。
- **Windows 包**改用魔虎当前的运行库（不再需要 onnxruntime.dll）。
