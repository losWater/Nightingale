# 调根台通用版设想（作者 2026-10-01，留待另开对话）

现有网页版：https://claude.ai/artifact/YB6pk9e5oFNFe6K1gyajjx
源码与数据：scratchpad/viz（model.js 评分、app.js 界面）；数据导出 `construct/export_viz.py`；评分口径同 `construct/model.py`（与引擎逐项核对一致）。

## 已定范围

- 只适配音形方案（双拼音码 + 字根形码），不做纯形码。
- 做成桌面软件（exe 或全平台），以便：加根、删根（需重新拆分）、本地保存与导出更方便。
- 词库由用户自己导入，不保证有词频。没有词频时，字词冲突按条数计，或按用户给的排序计。

## 需要通用化的部分

1. 数据导入：字表（字、读音、字频、拆分）、字根与归并、当前键位、词库、当量表/指法表；优先读 chai 配置和元素文件，以及形码盒子格式。
2. 编码规则：双拼方案可选；取根规则（首末等）与码长；简码规则（固定名单/按频自动、三简分配、有简让全）；字频按字或按读音（读音即字）。
3. 评价体系：指标库按当量表精确计算（不用夜莺退火校准的实打近似）；门禁、权重、参照方案（记 0 分）在界面上设定；可选的语料实打。
4. 字根操作：锁定、区域约束、互斥、归并/拆组；加根删根接拆分引擎。
5. 配套：导出码表（txt、Rime）、字根图、chai 配置；布局对比视图；每人各存各的；大数据量时后台线程与增量重算。

## 现有网页版已有的功能（可直接沿用设计）

拖根换键、点组看 26 键得失与算法喜好、门禁与指标实时变化（对照/上一步）、分档当量表、重码/字词冲突/没拿到三简追溯（冲突可按字频/词频/严重程度排）、"这一步改了什么"明细、按冲突自动修（找不到时全量扫描）、撤销重做、云端保存与载入、起点/对照可选已保存布局。
