# 多音字分读音频率重建（2026-09-30 起）

## 问题
2.0 的分读音字频（`03_字音频率审计`）按**词表**分配：多音字在词内按词定音，单字成词的用法（助词 地/得/着、了 等）无词可依 → 漏计或进待分配。
症状：地 de 仅 2%、了 liao 34%；纤/茜/咋 简码落在罕用读音；次要读音无保护。雾凇 8105 字表的单字权重更粗（地、长、行、得各 50%，了 liao 0%），不可作替代。

## 方法：从连续文本数
1. 语料（`reading/fetch_corpus.py`，不入库）：6 体裁 × 800 万汉字 = 4800 万字，均繁转简。
   | 体裁 | 来源 |
   |---|---|
   | news | MNBVC news（人民日报，仅 1990 年后） |
   | wiki | MNBVC wiki（zhwiki 2023-03） |
   | zhihu | MNBVC qa/zhihu |
   | forum | MNBVC 北大树洞 |
   | webnovel | wdndev/webnovel-chinese |
   | classic | qhchina/100_top_chinese_novels（现当代名著） |
2. 第一遍（`reading/pass1.py`）：pypinyin 词典分词全量跑。多音字在多字词内 → 词典定音直接计数；单字成词 → 计总数并按（体裁，字）抽样至多 200 处。
   结果：多音字出现 644 万次，其中单字成词 406 万（63%），涉及 311 字；的、了、和、说、都、还、会、大、得、地、着 占绝大多数。
3. 第二遍（`reading/pass2.py`）：g2pW（BERT 上下文消歧）逐条标注抽样位置；按抽样比例放大回总数。另抽词内样本 15 处/字/体裁，与词典读音对照，估计词典路准确率。
4. 大陆读音校正：g2pW 训练语料偏台湾读音（实测 “我和他” 标 han）。凡 g2pW 结果不在字音基准读音清单内的计为库外，另列台湾读音对照表人工确认。

## 工程备注
- g2pW 批处理反而更慢（批16 ≈ 60ms/条，批1 ≈ 30ms/条），多进程争内存带宽；采用单进程、批1、6 线程，约 27 条/秒。
- 抽样误差：每字每体裁 ≤200 样本，六体裁合计 ≤1200，比例标准误 ≲ ±1.5%。

## 结果（2026-09-30）
- g2pW 18.9 万条完成；词内对照 g2pW 与词典一致 90.0%。
- 典型修正（新 vs 03）：地 de 30.5%（旧 1.9%）；都 dou 90.6%（旧 41.5%）；了 liao 3.7%（旧 33.9%）；谁 shei 98.8%（旧 0%）；的 di 0.7%（旧 13.7%）。
- 全表逐字对比：`reading/out/新旧对比.tsv`（不入库，可由 pass3.py 重建）。

## 第二版口径（2026-09-30，替代第一版“单字成词”口径）
第一版发现两处系统问题：① pypinyin 词典只收需特殊读音的词，熟悉/成熟 等被切成单字，误送 g2pW；② g2pW 偏台湾读音（熟 shóu、劲 jìng、塞 sè、薄 bó、厦 xià、柏 bó、曝 pù……）。
第二版：
1. `sample_all.py`：对**全部**多音字出现位置均匀抽样（总频前150字每体裁200处，其余40处），共 18.8 万处；每处记 pypinyin 整句读音与 jieba（无HMM）是否单字成词。
2. `label_samples.py`：g2pW 逐处标注（复用第一版 4.5 万条缓存）。
3. `build_basis.py`：默认采用 g2pW；台湾特有读音（REJECT）改用 pypinyin；文白异读的白读仅单字成词时采用，其余计入 `口语频率`（血、熟 不计，因 g2pW 在词内也标白读）。
4. Claude 审校（`reading/审校裁定.json`，含逐字依据）：前 277 个实测多音字逐字核对，20 字按大陆读音改定；爪、粘 取暂定值，茜 按实际口语 xī 为主（作者 2026-09-30 裁定）。

## 作者裁定（2026-09-30）
- 整字总频沿用 2.0，只替换多音字各读音份额；语料出现 <30 次沿用 2.0。
- 口语异读另列 `口语频率`，退火权重默认 0.5。
- 著 只用现代体裁。
- 作者不逐字过目：Claude 把关，拿不准的交作者。
