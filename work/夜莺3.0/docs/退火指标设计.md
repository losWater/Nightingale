# 夜桜退火指标设计（草案，2026-09-30）

状态：四处 ❓ 已由作者裁定（2026-09-30，见第 7 节）。尚未修改引擎、未启动退火。

## 第一原则：读音即字（作者 2026-09-30）

> 多音字的每个读音当作独立的字，按它自己的字频决定一切：所在层级、有没有简码、候选位置。

以往的主读音硬保护、“字有简码”按整字判定、多音字让位逐条裁定等，都是多音字字频没分对而打的补丁。夜桜在正确分读音字频（docs/多音字频率重建.md）的基础上直接执行本原则，**撤销主读音硬保护**。

层级定义：前 N = 前 N 字的主读音 + 频率不低于第 N 字的次要读音。按当前字音基准：

| 层级 | 读音身份数 |
|---|---|
| 前300 | 300 + 2 = 302 |
| 前500 | 500 + 4 = 504 |
| 前1500 | 1500 + 21 = 1521 |
| 前3500 | 3500 + 71 = 3571 |
| 前6000 | 6000 + 184 = 6184 |

前1500 新增的 21 个次要读音：地de 长chang 了liao 乐yue 重chong 得dei 行hang 调tiao 都du 的di 着zhao 似shi 什shi 还huan 着zhuo 给ji 藏zang 觉jiao 角jue 没mo 曾zeng。

## 第二原则：形码只对形码管得到的字负责（作者 2026-10-01）

> 字频加权的测评（如形码盒子/虎码测评站）衡量整体打字体验是合理的；但用它来**设计**音形码的“形”就不合理：
> 最高频的一批字由一二简（纯双拼）打出，形码根本管不到，却在加权里权重最大，导致形码部分的手感被稀释、被掩盖。

- 形码设计的衡量对象：**用到形码的读音**（三码及以上；排除固定一二简），在其内部按字频加权。
- 目标是**均衡**：形码部分的键对当量向双拼部分看齐。当前（88 万字实打与上述口径）：
  双拼 1→2 ≈ 1.335；2→3 ≈ 1.31–1.35（已大致均衡）；**3→4：2.5 为 1.386，最好候选 1.358**——“头重脚轻”在 3→4。
- 设计目标：**3→4 降到 ≈1.335，2→3 不高于 ≈1.335**。
- 教训：第一轮正式赛（512 组）的目标函数与评分均按全体读音字频加权，60% 权重落在一二简读音的全码上，结论不可直接用于形码设计。

## 0. 背景：为什么要改

- 2.0 最终配置（54_补删鹿旁保留羊南心四起点试跑 / final_config.json）中，`key_distribution`、`pair_equivalence`、`phonetic_shape_transition_equivalence` 权重全为 0。生效项只有：全码有效重码（全局 300、前3000 另加 80）、简码三码奖励（分层）、简码加权指法（前1674：同指大跨排 82.5、小跨排 15）、字词避重 0.1。
- 没有任何一项约束第 3、4 码落在哪个键。字词避重反而奖励把末根放到稀少韵母键（二字词第 4 码 = 次字韵母键）。
- 结果（134_字根热力，前3500字、字频加权、全码）：第3码 p 10.3% 排第1；第4码 p 15.8%、t 11.0%、q 10.0% 排前三——恰是小鹤第2码最稀少的键。
- 换成自然码后第2码最稀少：p 0.74%（un）、t 0.85%、q 1.19%、x 1.34%（ie）、w 1.50%（ia/ua）、d 1.90%、c 1.93%（本目录 lib/shuangpin.py 计算，小鹤转换与字音基准 8454 条逐条一致）。p 更稀少，w、x 成新风险键。

## 2. 新增 A：分码位键位负荷

对第 3、4 码分别统计各键的字频加权使用量 u₃(k)、u₄(k)。

- 口径 ❓：
  - **实际打法（建议为主）**：有简码按简码实际敲的码（三码简码只计第3码），无简码按全码。反映真实手指负担。
  - 全码（建议为辅/报告）：每字四码都计。反映根布局本身、影响老用户学习。
- 目标份额 t(k) ❓：建议由当量表推出——键 k 越费力份额越低（如 t(k) ∝ 1/平均进入当量^α，α 校准），26 键归一。作者有自己的指力分级则用作者的。
- 损失形式 ❓：
  - **单侧超载（建议）**：L = Σₖ max(0, u(k) − t(k))²。只罚弱键超额，不奖励往强键堆（避免反过来把根挤成一团，重码交给重码项管）。
  - 按费力加权总量：L = Σₖ u(k)·cost(k)。单调、简单，但会一味往最强键推。
  - 对称分布匹配（libchai 原 key_distribution 形式，只限第3/4码）。
- 分层：前1500、3527、6000 累计层，高频层权重大。

## 3. 新增 B：分段当量

- E₂₃ 音转形：第2码（韵母键）→ 第3码（首根键）。libchai 已有 `phonetic_shape_transition_equivalence`，2.0 中权重为 0，夜桜启用。自然码韵母键全变，这一项的最优根布局必然与小鹤不同。
- E₃₄ 形内：第3码 → 第4码（首根键→末根键）。**需在 libchai 新增**。
- 均按实际打法口径、字频加权、分层；当量表沿用 2.0（54/frozen/当量表.tsv）。
- 不再使用四码混算的 `pair_equivalence`（第1→2码由双拼固定，会稀释可优化部分）。

## 4. 约束

- 音码：自然码双拼固定。
- 锚定同键：水火（含 氺 灬）；东西（含 覀）。
- 互斥：虫（默认含 𠀐）与 鸟系（鸟、鸟省、乌、鳥）不得同键 → 莺/萤可分。
- 一简、固定二简/简词：沿用 2.0 名单，按自然码重新落码。

## 7. 作者裁定（2026-09-30）

1. **口径：全码。** 简码选择复杂、无法预知，退火阶段不以简码结果为负荷依据；第 3、4 码负荷按每字全码统计（字频加权）。
2. **目标份额：由当量表推出**（54/frozen/当量表.tsv，越费力份额越低）。
3. **损失形式：单侧超载** L = Σₖ max(0, u(k) − t(k))²。
4. **硬目标 / 门禁**（对照：夜莺2.5 布局直接转自然码）：
   - 前 1500 字：全码**独占码位**（全码上无任何其他字）。字集口径：**以《通用规范汉字表》8105 字为核心字集**，扩展字不参与竞争、不计入门禁（作者 2026-09-30）。
     - 键位无关的必然同码（同音且首末根相同）豁免：前1500 中 22 字（如 吗/骂、比/毙、候/侯、查/栅楂；西/覀、水/氺 为锚定所致），清单由脚本生成。
   - 前 3500 字：尽量无重，重码个位数。
   - 前 6000 字：三码字最多比基线少 100 个。
   - 重码总对数最多比基线多 20 对。
   - p 不得进入前 20：第 3、4 码使用量**合并**排行（26 键中，全码口径，字频加权）。
   - 以上各层均按读音身份计（前1500 即 1521 个读音）。

## 8. 试跑结论与门禁修订（2026-09-30）

- 试跑 b1–b3（各 30 万步）：三码损失、重码对、p 排名、虫鸟互斥门禁均可稳定通过；重码对由基线 631 降至约 360–420。
- “前1521 全表独占”不可达：独占权重 1000、其余目标近乎失效时仍剩 5–7 个违例（形声字系列：如 马/犸/祃/码 须马组与石、犭、礻…诸组全部异键，多系列叠加后 26 键容纳不下）。
- 这些违例的撞码对象全部是更生僻的字，前1521 读音本身在全码位仍是首选。
- **作者裁定（方案 A）**：门禁改为有效重码口径——
  - 前1521：全码首选（不与更常用且键位无关签名不同的读音同码）= 0；
  - 前3571：有效重码个位数；
  - 全表独占保留为软目标，违例清单报告给作者。
- **固定夜莺2.5 全部一简（26）与二简（388，码为本字音节前缀者）**：试跑显示对独占、三码、重码几乎无影响，正式跑保留。特殊二简 by莺、eh鹤、en嗯、jv剧、xv绪 不在退火中表达，留待码表阶段。

## 9. 当量约束方向（2026-09-30，试跑中）

- A 组（超载 + p 排名门禁）虽过全部门禁，但字词避重由 94 升至 190–230（根被赶离稀少韵母键后与二字词码冲突增多）。
- 作者方向：去掉 p 排名门禁与份额超载，改以**当量**约束：保留 **二→三码过渡当量 E₂₃** 与 **三→四码当量 E₃₄**；全码当量 = 固定的一→二码 + E₂₃ + E₃₄，报告不另优化。
- 2.0 的实际打法当量 target200 **试关**（与“按全码评估”一致）。
- 依据：当量表按键对计成本，p 在异手组合中便宜（≈1.1）、同手组合中贵（进入均 1.54、离开均 1.69，p→k/l 达 1.9），比一刀切的排名门禁更贴近实际手感。
- 试跑：b5（E₃₄ 两档，target200 开）；b6（target200 关；仅E₃₄ / 等权 / 偏重E₂₃，各两种子）。
