# 一二简探讨（2026-10-01，仅为讨论记录，未改任何规则）

夜莺 3.0 目前**完整沿用 2.5 的一简（26）与二简（388）**。

## 精确最优（eval/opt_short.py，2.5 布局，逐音节枚举）
- 成本：按键对当量；二码位每位 1 字；2.5 留给词的二码位不给单字。
- 三种加权口径下，2.5 实际一二简离最优仅 1.5–2.1%：
  纯字频 2.11%｜词内 50% 逐字打 1.54%｜纯单字使用 1.92%。
- 最优解随口径漂移（如 m：们 / 吗 / 们；x：心 / 想 / 想），说明多数改动不稳健。
- 三种口径一致的一简：q 起→去、c 才→从、s 所→死；一致的二简 46 处，单处收益均为零点零几。

## 讨论要点
- 模型只计打字成本，不计**结构/好记**：
  - q=起 并非为分开 起/歧/跂 所必需（起 占 qi 二简亦可分开）；歧、跂 全码相同（止/足同组、末根同为支），只能靠歧拿三简区分。
  - 方案B（q=去、qi=起、qu=区）会让“其”掉到四码，不直观。
  - 方案C（再加 其=qir 三简、期退全码）三种口径下均略优于 2.5（0.03%–0.35%），且“字根字三码、带该偏旁的字全码”好记。
- “字根字优先”不能一刀切：丁、韦、丽 等常用度低的字根字会被不合理地抬上三简；需结合频率人工判断。
- 群友观点（鲸鱼会唱歌、江畔寻花2012）：一二简字不参与当量；高频字应在三码率中权重更高；生僻字三码无所谓（三码率不宜统计到前6000）；可考虑前4000重手感与三码率、后4000只求全码无重。
