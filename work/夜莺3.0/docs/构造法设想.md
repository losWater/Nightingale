## 已确定的部分

1. **根组首末标注**：前 3500 字按字频加权，根组越常出现在第三码（首根）越标"首根"，否则标"末根"。
   结果：`data/inputs/根组位置标注_前3500.json`（首根 51 组、末根 78 组；30 组摇摆，口 45%、点 39%、日 66%、横 58% 等）。
2. **字频权重**：读音按音节分组，组内按字频排名做幂律衰减。实测组内平均相对频率符合 1/k^2.58（指数衰减拟合差）；
   各音节陡缓差别大（de 很陡，ji、zhi 很平），统一指数还是用组内实际字频待定。
3. **逐音节处理**：按综合字频从高到低取音节（如 yi），列出以它开头的二字词占用的第三、四码并按词频标注。
4. **放根 = 打分，不落定**：给根组一个"预定位置 + 力量值"，力量值 = 放在这个键上有多好。
   - 首根：按「音码末键→该键」当量排序；目标是组内常用字尽量都分到三码（软约束，惩罚很重）。
   - 末根：常用字重码（硬约束）、字词避重。
   - 力量值有负分（字词避重等）和"死亡值"（放下去就常用字重码、常用字撞常用词，键直接判死）。
5. **死亡值是多组叠加的**：字字重码、字词冲突、抢三简都取决于两个根组的位置组合，
   可写成「单组打分 + 两两打分」的结构（成对马尔可夫场 / 带约束的二次分配一类），可用约束求解器在硬约束内求整体最优。
