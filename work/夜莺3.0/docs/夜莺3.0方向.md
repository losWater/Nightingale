# 夜莺 3.0 方向（作者 2026-10-01 定）

本仓库原为“夜桜”（自然码 + 2.5 字根）。经实验，作者确定真正目标是 **夜莺 3.0**：
**小鹤双拼**，以夜莺 2.5 为基础重新退火字根键位，尽量少改动。自然码版暂不推进。

## 规则集（退火目标与约束）
1. **形码成本**（第二原则）：只算形码管得到的读音（排除固定一二简）；三简读音成本 = 2→3 当量，打全码读音成本 = (2→3 + 3→4)/2；前1500层不加权平均、1500以后按字频加权，各占一半。权重 6000。
2. **四码**：前1500层四码读音 ≤120（硬）；前6000层三简读音 ≥3600（软）。
3. **字词撞码**（虎码秃版词库，二字词，按词频；按实际打：有一二三简者不算）：
   ① 前1500字 × 前1万词 = 0（硬）；② 前1500字 × 前3万词 尽量低（软，每次 30）；③ 前3500字 × 前1万词 ≤5（硬）。
4. **有效重码**：前1521 = 0（硬）；前3571 ≤9（硬）。独占为软目标。
5. **p 软约束**：形码按键中 p 占比 ≤4%（超出部分 × 10000）。
6. **换键代价**：每个根组离开 2.5 原键扣 10 分。
7. 固定 2.5 全部一简（26）、二简（388）；2.5 中首选为词的二码位（239 个，含 嗯 en 口语补读）留给词；虫鸟互斥；水火、车东西锚定同键。
8. 字频：夜桜字音基准（读音即字）。

## 当前最佳实验（C3B/g01q1s2，小鹤）
全部硬门禁通过；形码成本 1.345（前1500 1.332，低于双拼 1.335）；p 3.8%（2.5 为 7.3%）；四码 120（2.5 为 139）；
字词撞 [0,4,5]（2.5 为 [2,3,4]）；仅换 40 个根组，前1500 实际打码按字频变化 10%；实打键均当量 1.344 与 2.5 持平，小指干扰 1.52%（2.5 为 1.72%）。

## 2026-10-01 作者裁定：重码门禁改为「实际选重」口径

- 旧口径（沿用 2.0「有效全码重码」）：同音、全码相同、首末根组不全相同即计，不管有没有简码。
- 新口径：只看必须打全码的读音（无一二三简）。同一全码上，前面已有首末根组不全相同、也必须打全码的读音，才计一处。
  有简码的读音在全码位让位（有简让全），不参与。同根重码仍豁免。门禁数值不变：前 1521 = 0，前 3571 ≤ 9。
- 起因：殳放 q 与又同键时，搬（有三简 bjo）与扳全码同为 bjoq，旧口径记重码，实际打字无影响。
- 已改：引擎（Tier.actual）、build/gates.py、construct/model.py、调根台；make_inputs 默认 eff_actual=true。
- 新口径下：NB46、新新王前 3571 选重 2 处（挫、荆，旧口径 9）；2.5 为 0/10（旧口径 15/58）。

## 2026-10-03 无一简版（供虎码式整句使用）

- 背景：虎码整句要求码表没有一简；整句打法不考虑词，字词撞码不在乎。
- 方案 C（`release/no_yijian.py`）：26 个一简字改用本音二码（的 de、是 ui……）；原二简字让出二码去三码，三码被字频更低的读音占着就抢过来，被抢的退回全码（德、詟、弑、疣、瓿、期、盒、箫、摛、歌、疚、蔡、刃、挝、溺、龛）。
- 结果（实打 88 万字）：字均键数 3.294 → 3.488（+5.9%）；四码 4.4% → 4.6%；前 1521 选重 0、前 3571 选重 2（不变）；前 1500 四码 124（≤125）。
- 作者裁定：同一套 NB46 布局兼顾常规与整句两种打法，不为整句版另调布局。试验表：~/Downloads/夜莺3.0_NB46_无一简试验版_普通单字表.txt。

## 2026-10-03 整句评测（虎整句 D89-r3 解码器复刻）

- 工具：`tool/sentence/`（tsent.py 复刻五元模型、词先验、码表索引与集束解码；eval_sentence.py 评测；analyze_errors.py 错误分析）。未复刻纠错、提前上屏、学习、补充词。
- 测试：6 套测试句全部，按标点切小句（≥2 字）110290 句、87.5 万字；每字打其读音本码；逐字准确率按编辑距离。
- 结果（逐字 / 小句全对）：虎码 99.85% / 99.5%；夜莺现行 81.16%；C 原样 87.73%；C+前1500多音字白名单 99.77% / 99.2%；**C+按读音取本码 99.90% / 99.6%**。每字击键：虎码 2.349，夜莺 C 2.534。
