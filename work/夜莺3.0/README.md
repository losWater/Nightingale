# 夜桜（Yozakura）

以夜莺 2.5 字根集为基础、适配自然码双拼的音形码。

## 已定
- 音码：自然码双拼（前两码）。
- 字根集：沿用夜莺 2.5，不重选根。
- 根的键位：在自然码下重新退火（作者 2.0 定稿后有新发现，需纳入目标）。
- 夜莺仓库只读参考，不在其中写入。

## 作者新发现（2.0 定稿后）
1. **低频韵母键被塞满字根**：p、z、q 等键对应的韵母在双拼中本身低频，前两码几乎不用。全局负荷/当量指标因此认为这些键“空”，往第3、4码加根不伤指标。
   字词避重进一步推动：二字词第4码 = 第二字韵母键，同样稀少于这些键，把末根放上去可减少字/词码重合。
   结果：只统计后两码，p 在26键中排第三——全局指标好看，实际三四码频繁打弱键。
   → 夜桜目标函数须**按码位**评估键位负荷与指力，第3、4码单独约束；自然码的低频韵母键（p=un、x=ie、z=ei、b=ou、w=ia/ua 等）会成为新的“p”，需专门监控。
   → 避重与三四码手感存在结构性冲突，须显式设定权衡（如避重门禁 + 门禁内优化后两码手感）。
