# 夜莺 Rime 拆分反查测试补丁

适用于本次发布的 20260911 夜莺 Rime 包，Windows 小狼毫环境已测试。

输入 ~ 或 `，再输入完整拼音或小鹤双拼。例如 ~han、~hj、`han 都能查汉的拆分；候选显示“氵＋又 · hjbq”。按空格或数字选择汉字，Esc 取消查询。

两键输入可能同时符合全拼和双拼，查询会合并对应候选并去重。当前为单字查询，不做整句反查；输入完整音节后显示结果。

将补丁解压到 Rime 用户目录并重新部署。请先备份同名方案配置；本补丁更新主力、轻量、形码三个方案及所需 Lua 文件，不含模型、词典或个人学习数据。轻量包用户的方案列表仍可只保留轻量和形码。

拆分取自维护中的核心及扩展拆分表，展示名称使用最新映射（含贝字框），查询显示已有四码入口。查询数据仅首次进入反查时加载；反查不调用整句模型。

## F2 持续查询

两位双拼或三码后按 F2 进入核心字查询，继续输入和退格可收窄、放宽编码前缀，选字上屏后退出，再按F2保留当前编码恢复普通模式。例如 yc → F2 → b 与 ycb → F2 均可查尧。
