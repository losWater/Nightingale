# 字词避重选词实验

可用候选池95,223词、57,249个四码码位。优先使用最新复核结果；原前60000词待核项不从旧表重新引入，外围候选沿用同一分歧检查。

比较等量60,000词：直接按综合排名选取，与保留前40,000个可用常用词再补不同码位。这里的常用前40000指排除待核后的可用候选，不是原词频表前40000。

|指标|直接高频|常用加补位|
|---|---:|---:|
|词数|60,000|60,000|
|独立码位|37,925|48,046|
|重复占位词数|22,075|11,954|
|全候选码位覆盖率|66.25%|83.92%|
|全候选排序指数覆盖率|95.07%|99.65%|

补入20,000个此前未覆盖码位；新码位不足时按原排序回填0词。独立码位净增加10,121个。

## 口径与限制

- 只测选词覆盖，不代表已经减少多少实际字词重码；尚未运行2.0退火。
- 码位排序指数汇总使用整个共同候选池，避免选一个代表词后丢掉同码词贡献。原始词频分来源保存，未跨来源直接相加。
- 排序指数覆盖率不是实测文本覆盖率。候选读音和词条质量仍有未逐词验证部分。
- 当前根键位未定，本实验不使用1.0键位声称2.0避重成绩。
