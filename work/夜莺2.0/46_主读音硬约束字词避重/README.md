# 主读音硬约束实验

1643个常用字按自然分音频率选主读音。每个受保护条目的简码或全码至少一处为首选；其他读音仅报告，不触发淘汰。清单来自45号实验，字、拼音及输入索引已逐项校验。

- 新增可行性接口，每次目标计算完成后检查；不可行提案无条件拒绝，仍使用原有拒绝变更缓存回退流程。
- 起点不可行立即退出；最后完整重算再检查。为防自动调温阶段绕开限制，启用保护时必须提供明确降温时间表。
- 功能由 NIGHTINGALE_PRIMARY_GUARD 指向 guard_indices.json 启用；未设置时旧引擎语义不变。保护清单与elements.yaml必须成套使用。
- 短跑1000步核验通过，坏起点拒绝，原生码表重编码逐字节一致，缓存误差为0。
- 原权重、2倍、4倍共3组各50000步，全部从43号s2_w50可行结果重新开始，使用相同随机种子；同起点原权重续跑是必要对照。
- 当量、跨排和其他目标参数不变，只有字词软碰撞系数不同。本次不修改字根、拆分、读音或字频。
- 最多两任务并行，资源守护保留；数据全部保存在E盘。

本实验验证“硬约束内能否继续改善字词避重”，不是多种子稳定性或全局最优证明。强约束可能限制搜索可达区域。
