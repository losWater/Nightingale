# 新增龟后，龟字底的使用情况

8105核心字中，原来只有龟、阄使用龟字底；新增龟根后分别拆龟、门＋龟，龟字底使用数从2变为0。

现有18770扩展字维护拆分中有5字使用龟字底。新增龟根后，对这5字重新运行Chai，均仍保留：

|字|新增龟后拆分|
|---|---|
|電|雨头＋龟字底|
|竜|立＋龟字底|
|滝|氵＋立＋龟字底|
|槞|木＋立＋龟字底|
|篭|竹头＋立＋龟字底|

结论：核心字范围已无用途，但在现有扩展字范围仍有5字使用，不能称为全字库幽灵根。这里只检查新增龟的影响，未试算删除龟字底后的替代拆分，也未批准删除。龟字底目前归田组，删除它只减少具体根形，不减少独立组数。
