# 夜莺 2.0 码表概念与规则

> 整理日期：2026-09-14。来源标注：【概念】为用户本日口述的基础概念；【裁定】为本日对话中用户明确确认的规则；【待定】为尚未定案。
> 本文件的目的：让后续所有脚本和 AI 在动码表前先读到这些规则。今天查出的多处问题，根因都是"规则只在用户脑中，脚本作者不知道"。

## 一、基础概念【概念】

1. **音形**：每字编码 `ABXY`。`AB` 为双拼（小鹤方案），`XY` 为形码（夜莺字根，用户自研）。
2. **定长 / 不定长**：N 码定长 = 每字恰好 N 位；N 码不定长 = 每字最多 N 位可更短。三/四/五码各有两种。夜莺为四码。
3. **全码**：每字唯一的完整编码 `ABXY`。
4. **简码**：全码前缀 `A` / `AB` / `ABX`，即一简 / 二简 / 三简。用途：常用字省键；防重码。
5. **重码**：多字全码相同（全码重）。**选重**：候选位多于一个时需选择的动作。圈内无统一定义，按语境理解。
6. **出简让全**：字有简码时，在全码位让位给其他内容，自己退到次选或更后，仍在候选中。**出简不出全**：全码位不再出现该字。**夜莺采用出简让全。**
7. **无理码 / 容错码 / 用户自定义码**：**码表成型后**，出于手感或个人习惯为个别字额外加入的不符合规则的码。性质是附加物：去掉全部这类码，剩下的仍是规则完整的码表。因此**不参与任何规则判定**；正确流程是规则表完成后再叠加。
   - 无理码也包括**词的无理码**：`ak`=突击步枪、`xing`=彳亍、`woc`=我了个大草 这类，性质相同。
8. **词语编码**（形码规则，词全码恒四位）：
   - 二字词：每字前两码 `AB`+`CD`（本质是打双拼）
   - 三字词：三字首码 + 末字次码 `acef`
   - 四字及以上：前三字首码 + 末字首码（中华民国 `vhmg`，中华人民共和国 `vhrg`）
9. **简词**：码长 < 4 的词条（你好 `nh`、为什么 `wsm`、`y`=一个人）。四字及以上词配标准四码**不算简词**。
10. **四码词** = 四个码的词，不分字数。
11. **快符**：为了更快地打**符号**而设的特殊入口，例如 `w` 的次选是 `？`。快符只关乎符号；`xing`=彳亍、`ak`=突击步枪 这类不是快符，是词的无理码（第 7 条）。快符源：`D:\nightingale\symbo.txt`（当前 40 条）。
    - 实际应用没有这么泾渭分明：存在字与符号混合的条目，如 `ud` 次选 = `说道：“`。这类按人工指定处理，不强行归类。
12. **夜莺词库无三字四码词**：三字词一律走简词。原因：①简词更顺手；②三字四码 `acef` 会同时与单字全码、二字词全码撞位。

## 二、简码归属【裁定】

- 谁占哪个简码位是**人工判断**，理由异质，不能机械推导：个人习惯（摸占二简、模退三简）、手感补偿（平占二简因瓶的 `pkl` 更好按）、成组配对（春夏秋冬均三简）、连锁腾位（起占一简是为让其/期有简码）。
- 用户原话：这个码表绝大多数地方是合理的；审计只能列"不符合默认规则的候选"，由用户裁定，不得自动修。
- 衡量一个字需不需要简码，看**单字独立成词的频率**（潜几乎只在词里，浅大量单独用），不看原始字频。数据在 `03/分读音字频_审计版.tsv`。

## 三、二三简兼占与让位【裁定】

- 兼占：字已有一简/二简，同时占着三简。合法条件：该三简位无其他字竞争。
- 让位 = 该三简位**直接不出**占位字（区别于全码位的"退到后面"）。
- 竞争者自己已有一简/二简 → 不算竞争者。
- 竞争者在**主读音上已有简码**、来争的是零频的次要读音 → 不算竞争者（涌 chong、模 mu 案例）。
- 一简 + 二简同样适用（这占 `v`+`ve`，`ve` 让给着）。
- 用户裁定保留的兼占（不改）：`isa` 冲、`hop` 火、`zid` 自、`qtq` 却、`gjb` 敢、`bje` 般。

## 四、全码位字对字让位【裁定】

- 有简码（同读音前缀）的字在全码位退到无简码的字之后，仍在候选中。
- 容错码不算简码，不触发让位。

## 五、字词让位【裁定】

1. 字有简码 + 该码位有四码词 → 字让位。
2. 该码位多个词时，最多让一个词占首选。
3. 多个字全部可让位 → 整块后移保持原字序：`词₁ → 甲乙丙 → 其余词`。
4. 其中有任一字不能让位 → 整组不让：`甲乙丙 → 词…`。
5. 无简码但字频 > 5000 的字：顶上来的是**二字词**时默认让位；三字及以上词不让（防误打出一长串）。
5a. 扩展（2026-09-14）：**任何字**与三字及以上的词同码时一律不让位，即使该字有简码。规则 1 因此仅对二字词生效。
6. 人工指定（`64/码位人工指定.json`）的码位不动。
7. 【裁定 2026-09-14】"字有简码"按整字判定（任一读音有非容错简码即算），**但**字仅靠其他读音的简码被判可让位、而本读音有实际使用（`03` 分读音已分配频率 > 0）的，逐条人工裁定，不套阈值。本日 12 处：纤 xmic、茜 xime、咋 vatk、省 xkyb、剥 bcpg、奇 jiyt **改回字优先**；劲 jktp、秘 binv、叨 tctg、莎 somf、解 xpgv、什 uikc 维持词优先（`84_多音字让位逐条裁定`）。
   - 纤/茜/咋 的根因是简码派在了罕用读音上（简码归属问题），本次只改让位，归属另议。
   - 注意"待分配/原始总频"两列是字级值在读音行重复，不可求和。
   - 词词阶段待办示例：`jiuu` 首选是技术，奇数排后（跨组次序）。

## 五之三、鲸凉鹤 1.1 词库说明要点（原文：`91/参考_鲸凉鹤1.1词库说明_文本.md`，来自 `D:\qqfile\鲸凉鹤1.1词库说明 (1).docx`）

以下是鲸凉鹤作者自己写明的约定，对应到我们审计出的各类：

- **20 组整音飞键**（cs→cl、dc→dl、gr→gp、gv→gi、jm→jz、lp→lf、mj→mr、mu→mx、nj→nz、pi→pe、pk→px、po→ps、qx→qo、tv→tl、uj→us、vg→vk、xq→xo、yj→yf、yu→yg、zs→zl）：**原码保留、飞键是附加打法**（"po 音字词都能用 ps 代替打出"）。核对（深夜）：源表里这 20 组飞键形约 1.4 万条（每个词在原形、飞键形下各一份），**我们的普通词表里一条都没有**——56 那一轮"已知飞键还原 15477 条"就是把它们改回原形。用户裁定飞键要去掉，结果是本来就已去掉，无需再动。我们登记表里的"声母/韵母口音替换"（225+125）不是这 20 组，是 p→b、t→d、a→j 这类零散替换；s→u 是兼容打法，保留。
- **6 个飞单字**（一 yi→ei、百 bd→be、几 ji→je、向 xl→xj、之 vi→vp、起 qi→qe）：该字所在的**所有词**都飞，目的是**去重**（eifu 一副 vs yifu 衣服；vpui 之时 vs viui 知识）。= 我们 C 类里的"一 e→y"。已按用户裁定改回 y，代价是 一 系词重新与 衣/依/以 系词同码——飞键处理阶段要记得这一点。
- **`e` 的无理字**（毕 beb、几 je、鸡 jey、立 lew、起 qe…）：单字层面，我们用自己的单字表，不采。
- **AABB 叠词放在 AB 词的第 4 选**（高高兴兴 = 打 高兴 gcxk 选 4）：= 我们的 A 类"叠词写法"。保留正确。
- **`o` 引导**：快符（os…、ov——、ow？）；叠字拼字（oerrf 仌）；**300 常用繁体 `of` 引导**（ofda 達）；四码连击叠词改 3 码（occ 草草、odd 呆呆）。我们 G 类里的繁体条目来源于此。`oj**` 在说明中未出现（1.1 表中实有），已删。
- **数字**：`o` 前缀数字词（十五 ooag 等）说明未单列，实表中存在，已裁定保留。
- **鲸凉鹤简词建立在它的无理一简之上**（a=也/要、o=都/时、e=一、je=几），其二简词（ab 也不、co2 此时、do3 的时候、ax 也许…）依赖这些一简。我们的一简是 a=啊、o=哦、e=而，**所以鲸凉鹤简词对我们而言大多等于无理码**——这就是第 4 步（简词）要面对的核心事实。
- 鲸凉鹤四重候选、二简词按"同字关联/近反义关联"成串设计、三码三字词只作锦上添花。
- 说明中**没有**关于 行 xk/kx 之类的手感约定；畅行 ixkx、让行 rxkx、妄行 wxkh 在说明里找不到依据。

## 五之四、简单鹤"强规范打词规则"与普通词取舍（原文：`91/参考_简单鹤音形无上秘籍_文本.md`）

简单鹤更新日志的规则：**你我他她它、的地得、在了出到 等，尽量不要打词，相关的词是无穷的**；建议拆的词类：助词（的地得所／了着过／呢吗吧啊）、副词、量词、数字、代词。真的常用的靠简词（我们、一个、的时候）。另：尽量不要打三码三字词；重码重灾音节 shi/yi/zhi/ji/yu 的组合。

对普通词表的含义：由语法功能字组成的二字词没有边界，不该整批留在普通词表里，只留真正常用的。
- 用"页面点名的功能字"做整字匹配会误伤（爱情、安全、标准、必须 都含所谓功能字），所以判据收窄为真正的语法虚词：的地得所了着过呢吗吧啊／你我他她它这那哪此谁咱／都也就还又才很太最不没别只仅全总再已正要曾刚将仍常能必／个只／数字。
- 收窄后命中 14745 个二字词。**裁定（`94`）**：动词+助词类（末字 了着过呢吗吧啊的，2268 条）全部保留——分词工具会把它们切开，08 词频对这类不可信（忘了、走了、很好 都近乎零记录），而它们是真词；其余 12477 条不用排名线、只看"六源语料出现过没有"：零出现 5944 条删（就往、派我、它敢、帮他、到你），出现过 6533 条留。挺好（173 次）留、停好（0 次）删，符合"正经词 vs 拼出来的"直觉。
