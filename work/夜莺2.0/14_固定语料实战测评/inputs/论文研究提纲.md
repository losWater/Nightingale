# 夜莺码：从首末根原理到词码空间覆盖

> 实验设计与展示提纲。结果栏在实验完成后填写；不预设结论。

## 1. 研究缘起

音形码的单字通常由固定音码与可调整形码组成。以夜莺为例：

```text
abxy = 双拼音码 ab + 首根 x + 末根 y
```

形码可以优化单字区分，但二字词的四码由读音或固定组词规则决定，字根布局无法改变词码本身。因此，常用单字与常用词占据同一码位，是音形方案必须单独处理的问题。

本研究关注两个可检验命题：

1. 在真实词库中，语音二字词占用的不同四码位较少，码位分布比形码词更集中，并随词库扩展更早出现边际饱和。
2. 在相同词数和相同优化预算下，“高频词＋新码位词”的覆盖式训练集，比纯词频训练集更能减少隐藏数据中的字词撞车。

## 2. 核心概念

### 2.1 词数不等于码位数

多个不同词可以共享一个四码词位。继续向词库增加同码词，会增加词数，却不会向退火提供新的避让位置。因此需要同时统计：

- 收录词数；
- 唯一四码位数；
- 新增词带来的新码位率；
- 每个码位承载的词数及其分布。

### 2.2 码位覆盖训练

训练集不只是常用词表，而是由三部分组成：

1. 高频二字词：代表真实使用压力；
2. 低频但提供新四码位的二字词：扩大可见的词码空间；
3. 常用四字简词：补充四声母组合造成的独立压力。

### 2.3 数据隔离

训练、验证和测试必须按“四码位”切分，而不只是按词切分。若训练集和测试集包含不同词、却共享同一码位，仍然构成信息泄漏。

## 3. 统一词码生成规则

为了公平比较不同方案，所有方案使用同一词库和同一组词规则，只替换单字全码表。

设各字全码如下：

```text
一：abcd
二：efrg
三：hijk
四：lmno
五：pqrs
```

统一规则：

| 词长 | 规则 | 示例 |
|---|---|---|
| 二字 | 两个字各取前2码 | 一二 → `abef` |
| 三字 | 三个字各取首码＋末字第2码 | 一一二 → `aaef` |
| 四字及以上 | 前三字各取首码＋末字首码 | 一二一二 → `aeae`；一二三四五 → `aehp` |

该规则只读取单字码表中的字母位置，与方案具体如何拆字无关。对 `abxy` 型音形码而言，二字词 `abxy + cdmn` 会自然得到 `abcd`，即退化为两个完整双拼音节。

统一生成器：`scripts/build_word_codebook.py`。

脚本同时报告：有效词数、缺字、唯一词码位数、重码码位数、重复词数、最大码位容量及新码位率。

生成器不假设方案一定使用26个英文字母：码元按原表保留，兼容带分号、逗号、句点等键的32码元方案。跨方案比较时除报告唯一码位数外，还必须同时报告字母表规模及其理论四码空间，避免把32码元方案与26码元方案的绝对容量直接混为一谈。

## 4. 实验一：语音词码与形码词码的空间比较

### 4.1 研究问题

在完全相同、按频率排序的词库上，语音词码是否比形码词码更集中，并更早进入码位新增趋缓区间？

### 4.2 比较对象

- 小鹤双拼二字词码；
- 夜莺单字全码生成的词码；
- 简单鹤单字全码生成的词码；
- 虎码单字全码生成的词码；
- 可选：另一套成熟形码作为复核。

不得使用各方案自带词库；全部由统一脚本重新生成。

### 4.3 词库规模与分档

正式实验冻结两套各20万词的统一词库：

- 纯二字词库：200,000词，用于四码位覆盖、重音和五码辅助研究；
- 普通混合词库：200,000词，保留2—10字的真实混合词长结构，用于通用组词法比较。

两库统一按综合使用频率分档：

```text
S：前2,000
A：2,001—10,000
B：10,001—50,000
C：50,001—100,000
D：100,001—200,000
```

累计曲线依次截取前：

```text
1,000 / 2,000 / 5,000 / 10,000 / 20,000 / 50,000 / 100,000 / 150,000 / 200,000
```

二字词与四字简词分开统计，不混合解释。

词频证据以BCC多领域、对话、新闻、文学，SUBTLEX字幕和CLD微博为主；Jieba官方大词典与THUOCL仅补充长尾和领域覆盖。所有来源排名、支持数和综合得分保留在TSV中，避免把“被词典收录”误写成“实际高频”。

### 4.4 指标

- 唯一四码位数 `U(N)`；
- 码位覆盖率 `U(N) / 26^4`；
- 新码位率 `U(N) / N`；
- 每新增1,000词产生的新码位数；
- 重码码位数；
- 重复词负担 `N - U(N)`；
- 平均／中位／95分位／最大码位容量；
- 码位容量分布的熵或基尼系数（可选）。

### 4.5 图表

1. 词数—累计唯一码位曲线；
2. 词数—每千词新增码位曲线；
3. 各方案码位容量直方图或CCDF；
4. 高频同码位的具体案例表。

### 4.6 结论边界

实验只能证明真实语料中的“经验占用空间”和集中程度，不能仅凭四码形式宣称某类方案的理论空间无限或有限。

## 5. 实验二：覆盖式训练对字词撞车的改善

### 5.1 对照组

在词数完全相同的前提下构造：

- A 纯词频组：直接选择最高频词；
- B 随机补充组：高频核心＋随机低频词；
- C 码位覆盖组：高频核心＋能提供新码位的低频词。

可增加消融组：去掉四字简词、去掉多音字处理、只使用单一字频表。

### 5.2 严格控制变量

- 相同根集和拆分；
- 相同单字保护资产；
- 相同目标权重；
- 相同退火步数、线程数和随机种子；
- 相同训练词数；
- 相同隐藏验证集与最终测试集；
- 不使用无理码改善核心数据。

### 5.3 单字保护层

- 1674黑洞核心字集：1674个唯一汉字、1800条读音资产，目标为普通重码0；
- 3527质数常用字集：3527个唯一汉字、3761条读音资产，重点压低重码并提高三码率；
- 所有读音共同参与，防止多音字用冷门读音“偷位置”。

### 5.4 主要指标

- 训练集字词碰撞；
- 隐藏验证集字词碰撞；
- 最终测试集字词碰撞；
- 1674层与3527层分别撞词多少；
- 普通重码与仅全码重码；
- 三码率与加权键长；
- 手感指标：左右手、各排、小指、跨排、同键连击；
- 12条独立搜索线的均值、中位数、标准差、最好值和最差值。

### 5.5 预期判定

若C组在相同训练规模和计算预算下，稳定降低隐藏集与最终测试集碰撞，且没有明显牺牲单字与手感，才能支持“码位覆盖训练有效”。只降低训练集碰撞不能证明泛化能力。

## 6. 公平性与风险

- 简单鹤存在多重编码及特定候选排序，需分别报告主码和全部容错码口径；
- 夜莺运行于搜狗自定义短语环境，完整句子输入与传统四码平台不同；
- 不同字频表会改变“前1500”含义，因此统一采用1674/3527混合资产；
- 各方案单字码表若包含简码和全码，统一生成器默认选择最长码，同长度多码取文件首项，并报告多全码字；
- 词库缺字率必须公开，不能让覆盖范围较小的方案因删词而虚假获益；
- 语料来源可能偏向书面、口语、网络、专名或特定领域，应报告来源与分层结果。

## 8. 最终展示结构

1. 为什么单字性能不能代表音形方案的全部体验；
2. 二字词的四码位为何成为独立约束；
3. 词数与码位数的区别；
4. 统一词库与统一编码规则；
5. 实验一：词码空间曲线；
6. 实验二：三种训练集的隐藏碰撞对照；
7. 首末根原理与1674/3527分层保护；
8. 单字、字词分离与手感综合结果；
9. 局限、适用范围与后续工作。

## 9. 一句话摘要（暂定）

> 夜莺优化的不是若干条具体词语，而是这些词语背后可复用的四码空间；通过首末根设计、混合字频保护和码位覆盖训练，可以在不依赖无理码的前提下系统降低高频单字与词语的码位冲突。
