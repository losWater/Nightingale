夜莺 2.0 正式版（2026-09-16）。音形码表：小鹤双拼 + 夜莺字根形码，四码定长，出简让全。

## 内容

- 字：8105 通用规范汉字 + 7391 扩展字（新华字典多出的字，含繁体旧字形），扩展字全码排现有字词之后，语料出现过的给三简。
- 词：普通词按四家方案（鲸凉鹤、简单鹤、魔然、虎码）共识筛选，词序三家投票；二字简词 952 条，三字词三码 17282 条。最终表 155139 条。
- 字根：130 组、404 根形；单字表可由退火起点 + 逐批裁定重放。

## Rime 两版共有

- 空格首选、分号次选、单引号三选；反引号双拼、两个波浪号全拼反查；F2 拆分提示。
- **Ctrl+数字**：第 N 个候选是码表候选 → 钉为该编码首选并上屏（记在用户目录 `yeying20_pin.txt`）；是整句/联想出来的词 → 按夜莺词规则加进 `yeying20_words.txt` 并上屏。
- **二字自动造词**：连续打两个字自动按双拼四码入用户词典。
- **Ctrl+Enter 主动造词**：上屏前按下，整段文字按夜莺词规则编码入 `yeying20_words.txt`，不限长度，带〔造〕标记，Shift+Delete 可删。
- 码表候选顺序不随使用频率变化：钉选在前，码表原序居中，造的词垫底。
- **简词进整句**开关（方案菜单 Ctrl+` 内，默认关）：默认整句只用单字与四码词，不混入简词，识别更稳；打开后简词也参与整句，主力版切换时重建整句引擎约几秒。

仓库内 `releases/v2.0/` 有同一份码表、挂接文件、字根拆分与规则文档；主力包因体积只在此处附件提供。
