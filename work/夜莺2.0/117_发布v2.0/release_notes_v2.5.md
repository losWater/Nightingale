# 夜莺 2.5

第一周实战反馈的集中更新。方案文件名、Rime 方案名（`yeying20` 等）保持不变，直接覆盖安装即可，个人词库不受影响。

## 词与词序
- 新增 277 个二字简词（二码），123 个已有简词按实战习惯调序；删去 `yo` 上的「有时」「一时」。
- 每个二码位最多保留 3 个候选（空格／分号／引号可选），多出的 63 个词删去二码入口，它们仍可用四码全码打出。
- **40 个二码位的首选词有变化**，如 `sl` 算了、`gm` 干嘛、`hg` 后果、`bt` 不停。
- 调频 13 处（机器、另一个、复刻、几个、基地、白鹭、那是、基础、转移、一波、否则、一份、喀）。
- 新增词：我靠、寓言、玉帝、凡间、才有、夜桜、全是、档位、做什么、巨构（`jugz`，原 `jvgz` 保留）。

## 单字
- `ufk` 改为「伸」，「什」退回全码 `ufkc`。
- `oot` 改为「喔」（噢保留二简 `oo`）；`ait` 改为「唉」，「哎」退回全码 `aitp`。

## 拆分订正
- 含「曲」的字统一为 囗＋横＋丨＋丨（如 蛐、澧、醴、體、農）。
- 「庸」族统一为 广＋肀＋用。**庸、慵、镛、墉、鳙 的全码随之改变**（如 庸 `yscr` → `yscz`），三简不变。
- 其余按既定拆分规则补齐一批生僻字（彖、衍、戌、卸、年、衮 等部件），共改 6 + 7 个生僻字的全码。

## 符号
- o 引导符号区删去逗号、句号、分号、引号及快符已有的符号（31 条）；假名区不变。

## 其他
- 虎娘：新增「夜莺2.0单字」纯单字练习码表；候选注释显示完整拆分。
