# 夜莺0.8.6 手感换重码扰动实验0002

## 设计

- 起点：夜莺0.8.5 G8C12冠军布局；
- 两份可复现的12根小扰动，每份分别跑A/B/C三档；
- 每卡50000步；前300有效全码重码保护8保持不变；
- A沿用0.8.5炉内权重；B、C逐步减弱三码奖励并增强大跨、小跨和音形换手权重；
- `+10/+20`是跑后有效重码预算，不是强制增加重码。

## 结论

1. 第一轮直接从冠军续跑时，A/B/C全部返回原布局；退火有正常探索，但G8C12仍是该局部盆地的最优解。
2. 小扰动成功跳出局部盆地，但没有候选真正使用`+20`重码预算：全体有效重码字均不高于基线560。
3. 当前权重变化主要拿“三码数”支付手感成本。最显眼的R2-C虽然当量下降0.001164、大跨下降0.053个百分点，但损失53个前6000三码，且换手下降3.273个百分点、单指微移增加0.225个百分点。
4. B档两条链的换手均跌至约48%，说明仅增大当前换手当量权重不能稳定等价为用户口径的左右手分离；必须继续把两种口径分开报告。
5. 本轮没有可直接晋级为0.8.6的候选。

## 下一轮方向

- 不再继续简单减弱三码奖励；至少先把前6000三码设为硬安全栏，例如不得低于3815或相对0.8.5损失不超过约15—20字。
- 将“全体有效重码字不超过基线+20”实现为候选筛选门禁，而不是期待退火自动用满预算。
- 手感目标采用单变量或小二维网格；普通组合当量、大跨、小跨、用户口径换手分别校准，避免多项同时改权重后无法归因。
- 若要让退火主动探索“增加低频重码换手感”，需要在libchai增加分层的低频重码预算/铰链惩罚；现有全局重码指标只能线性处罚，不能表达“560以内不奖不罚、580以上才罚”。
