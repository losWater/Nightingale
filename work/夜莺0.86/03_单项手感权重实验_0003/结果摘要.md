# 夜莺0.8.6 单项手感权重实验0003

## 设计

- 两份G8C12冠军布局的12根可复现小扰动；每卡50000步。
- 三码奖励、换手权重和字词碰撞目标固定为0.8.5值。
- 每个起点分别运行：A原参数、P普通组合当量权重2、L仅提高大跨权重至140、S仅提高小跨权重至40。
- 验收线：前6000三码不少于3812；全体8454身份的有效全码后置字不超过580（G8C12原始退火口径基线560，即允许+20）。

## 判断

1. 没有候选真正使用`+20`重码预算；总有效重码均低于基线560，说明当前优化瓶颈并非总重码门禁。
2. P档未稳定改善普通组合当量。R1-P守住三码和换手，但当量、大跨、单指微移、小指联动均差于G8C12。
3. L档能直接压大跨，但两链分别损失46和17个三码，同时小跨、微移、联动、换手多数退化。
4. S档能改善小跨，R1-S还改善微移，但会损失25个三码、显著恶化小指联动与换手；R2-S同样不达三码门槛。
5. 本轮没有同时通过三码门槛并在整体手感上优于G8C12的候选。

## 后续建议

- 暂停继续盲目加大现有Chai手感权重；它们不能稳定代表用户口径的微移、联动和换手。
- 下一步优先从既有256张卡和本轮候选中做统一口径帕累托筛选，确认是否已经存在“重码略多但实打手感更好”的布局。
- 若现有卡池不存在，再考虑把用户口径的单指微移、小指联动直接实现为libchai可增量计算的退火目标，而不是继续用大/小跨间接代理。
