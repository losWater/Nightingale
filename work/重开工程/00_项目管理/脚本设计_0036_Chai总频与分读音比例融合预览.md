# 脚本设计 0036：Chai总频与分读音比例融合预览

## 目标

修复BUG-0004：不再把SUBTLEX证据下界直接作为完整退火频率，而是从Chai恢复完整整字总频`m`，用当前裁决后的分读音证据提供字内比例，生成融合频率预览。

## 整字总频恢复

对同一字在设计0020原始Chai字音表中的频率：

1. 只有一个正频：`m`取该正频。
2. 有多个互不完全相等的正频：视为Chai已有分读音分配，`m`取正频之和。
3. 有两个以上完全相等的正频：视为同一未分配整字频率被复制，`m`只取一份。
4. 全部为0：`m=0`。

## 分读音融合

1. 单读音字直接取得`m`。
2. 多音字若当前退火候选自然频率之和大于0，以这些频率作为字内比例，使用最大余数法把`m`守恒拆分到现有读音身份。
3. 多音字若全部缺乏正频证据，不伪造比例，暂时原样保留Chai各读音频率并列入兜底异常。
4. “谁”仍输出普通融合预览，但最终退火阶段必须由特殊优化权重完整覆盖；本步骤不得删除特殊规则。
5. 仍未分配的单字证据只表示没有直接进入比例分子；若该字已有明确上下文比例，可据此拆分完整`m`，不等于把未决证据均分。

## 输出

- `Chai总频_分读音比例融合预览.tsv`
- `Chai总频_分读音比例融合异常.tsv`
- `Chai总频_分读音比例融合报告.md/json`

## 验收

- 8454字音身份、8105字覆盖不变。
- 所有具有有效比例的字逐字严格守恒。
- 报告零频数、正频转零数、频率总量及无比例兜底项目，不能只报告行数。
- 连续双跑哈希一致。

## 实施结果

- 状态：融合预览已实现并通过双跑验收。
- 输出保持8105字、8454字音身份不变。
- 识别17个“相等正频复制”整字总频模式。
- 8,095字严格守恒；61个多音字完全没有当前正频比例证据，因此保留Chai原分读音值。
- 61个兜底字中，51字原Chai值本身守恒；10个相等复制项目暂时不守恒，均在异常表明确列出。
- 零频字音由原Chai的336项变为264项；31个原正频读音经证据比例归零，103个原零频异读获得正权重。
- 原Chai字音频率求和2,522,799,818；融合预览求和2,521,220,566。差额主要来自相等复制频率只按一份整字总频参与分配。
