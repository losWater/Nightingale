# 脚本设计 0030：谁的优化权重裁决

## 背景裁决

`谁`在当前封闭读音集合中保留 `shei` 与 `shui` 两个读音身份。用户裁决：

- `shei` 对应输入音码 `uw`；该音位当前只有“谁”，位置天然唯一，因此保留身份但不参与退火竞争。
- `shui` 对应输入音码 `uv`；以“谁”的当前可审计总字频除以 4，作为退火时的有效竞争权重。
- 这是一条优化权重规则，不是自然语言频率判断；不得用它改写自然频率证据表。

## 输入与计算口径

1. 从 `SUBTLEX阶段性分读音频率表_封闭读音版.tsv` 汇总“谁”已经按读音落定的阶段频率。
2. 从 `SUBTLEX单字多音定案审计.tsv` 读取尚未按读音分配的“谁”单字总频。
3. 两者相加得到当前可审计的整字总频；不得遗漏已分读音频率，也不得把未分配频率重复计入两个读音。
4. `shui` 的退火有效权重为整字总频的 `1/4`；`shei` 的退火有效权重为 `0`，并明确标记不参与竞争。

## 正式规则资产

规则写入 `03_字音频率/特殊优化权重裁决.json`。资产内带当前输入快照断言；上游频率变化时，校验必须失败并要求重新裁决，不能静默沿用旧数值。

## 校验脚本

`scripts/validate_special_optimization_weights.py`：

- 只读正式规则和两张频率证据表；
- 验证读音集合、阶段频率、未分配单字频率与总频快照；
- 使用十进制定点运算计算有效权重；
- 输出机器可读 TSV 和人工报告；
- 不改写 8454、8105、自然频率表或最终退火输入。

- `shei / uw`：保留身份，不参与竞争，有效权重 `0`。
- `shui / uv`：参与竞争，有效权重 `13,213.75`。
