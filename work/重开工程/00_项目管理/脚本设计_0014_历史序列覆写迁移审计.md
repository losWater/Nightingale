# 脚本设计 0014：历史序列覆写迁移审计

## 状态

- 设计时间：2026-08-28 01:40 +10:00
- 状态：只读审计已完成；禁止整包迁移旧`sequence_overrides`

## 背景

旧`夜莺B/work/拆分规则.yaml`含39条最终序列覆写，但同一节混合了唯一规范结构、
结构性同拆处理、无理码和字词避撞顺取码。重开工程当前只允许恢复结构层资产，
因此必须先分层，不能按旧字段名整体继承。

## 初步分层

- 结构候选31字：乘、剩、嵊、年、承、兵、戌、戍、庚、羲、曦、爔、彖、缘、喙、
  篆、椽、掾、橼、瑑、禒、蠡、临、庸、墉、慵、镛、鳙、鄘、隶、逮。
- 编码层8字：骂、侯、媚、箭、裔、匕、椅、怡；当前阶段隔离，不进入结构表。
- 乘、剩、嵊已由新版“乘”传播式结构覆写接管，审计应识别为已迁移，不得重复应用。

## 输入

- 旧拆分规则中的`sequence_overrides`。
- 当前权威8105规范拆分表及根集。
- 当前普通人工拆分、传播式结构覆写和正式字架规则。

## 审计方法

1. 对31个结构候选，将旧目标序列按当前附属根和笔画名称归一。
2. 旧目标中出现非根时，通过当前规范表递归展开；无法展开立即失败。
3. 与当前完整规范序列比较，分为：
   - 当前已语义一致；
   - 已由新版其他规则接管；
   - 真正疑似漏迁；
   - 旧裁决与当前根集不兼容，需人工重新判断。
4. 对8个编码层项目只报告隔离状态，不计算为结构缺失。
