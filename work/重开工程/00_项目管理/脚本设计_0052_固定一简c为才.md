# 脚本设计0052：固定一简 c 为“才”

## 决策

用户裁决夜莺0.8的一简`c=才`，不采用纯频率自然竞争产生的`c=从`。

## Chai实现

Chai没有逐字指定简码所有权的独立字段，但音形资产支持`排序序号`：它控制保护层顺序和
简码竞争顺序，真实`频率`仍用于加权。当前“从/cóng”与“才/cái”分别位于频率序第59、
94，二者都在前300保护层中。

生成一份全量显式排序的派生退火元素表：默认排序与当前8454行完全一致，只交换
“从/cóng”和“才/cái”的排序序号。这样不改变300/500/1500/1674/3527/6000任何
分层成员，也不修改二者频率，只让“才”先占`c`，“从”继续竞争后续简码。

## 输出与门禁

持久脚本：`scripts/build_one_code_ordered_elements.py`。

输出：

- `夜莺0.8退火元素表_一简c为才.yaml`；
- 同名`.manifest.json`，记录输入输出哈希、交换身份和原始行号。

门禁：8454身份、8105字、除排序序号外字段逐项不变、排序序号为0—8453不重复全集、
所有既有分层成员集合不变、真实频率不变。随后以固定C07布局原生encode，必须得到
`c=才`且一简恰为26个。
