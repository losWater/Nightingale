# 脚本设计0066：冠军基础词性能试验

## 目的

为冠军C19（G9-C11，seed910011）生成不含777简词的基础综合字词试验表，并复算词—词
重码及单字全码—词码撞车。此步骤只评估，不继承0.7的无理码、谕旨、让位或候选顺序裁决。

## 输入

- C19的8454行`编码审计明细.tsv`，使用其中“全码”做字—词结构碰撞；
- C19普通单字试用表，使用其中“实际码”生成未经让位的综合试验表；
- 已审定`二字词_精选60000.tsv`；
- 已审定`四字简词_精选.tsv`（17860条四字及以上基础词）。

词库现有`code`必须是四码。夜莺词码仅取各字音码，当前全部方案没有飞键、只移动形码，
所以词—词码位在所有退火布局间不变。不得重新用单字最高频读音猜词中读音，否则会重现
“重蹈覆辙／弹电子琴”等多音词误码；本试验沿用已经校过的词库码。

## 输出

- 77860条基础词码表及无简词综合字词试验表；
- 词—词重码槽、额外候选数、最大候选数和具体明细；
- 单字全码—词码撞车明细，分别列最高频/最高排名二字词、四字词及数量；
- 前20000、30000、60000二字词分层碰撞；
- 机器可读JSON、UTF-8-BOM CSV和可读Markdown报告；
- 输入、输出SHA-256与行数门禁。

## 边界

综合试验表只用于观察基础结构，不实施旧0.7人工裁决，也不加入777简词。字词同码时暂按
文件顺序保留单字在前；因此它不是0.8正式发布表，不能据此直接固化让位。
