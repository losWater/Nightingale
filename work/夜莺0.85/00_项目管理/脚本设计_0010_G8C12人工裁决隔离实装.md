# 脚本设计0010：G8C12人工裁决隔离实装

## 目标

以已经核验的 G8C12 纯单字普通表为冻结基线，把 `04_G8C12人工裁决` 中已经确定的常规码位裁决和无理码转换成显式 `SET_SLOT` 操作，生成隔离假码表。

本步骤不改原始退火 `code.txt`、不覆盖纯单字基线，也不把人工码重新送回退火。

## 输入

- G8C12 `纯单字试用表.txt`；
- `G8C12_显式码位操作.tsv`；
- 裁决依据为 `单字码位裁决.tsv` 与 `无理码表.tsv`。

## 输出

- 普通格式假码表；
- 搜狗格式假码表；
- 包含输入哈希、目标码位调整前后候选和输出哈希的 JSON 验证报告；
- 验证通过后另行派生含快符搜狗版，不把快符混入基础补丁逻辑。

## 门禁

1. 每个目标码位只能声明一次最终候选；
2. 目标码位必须与裁决后的完整候选序列严格一致；
3. 未声明码位逐项保持原样；
4. 普通表与搜狗表反读后必须完全一致；
5. 搜狗候选序号必须从1连续排列；
6. 输出目录必须事先不存在，拒绝覆盖旧验证结果。

## 实现

复用已审计脚本 `work/重开工程/scripts/apply_manual_code_table_decisions.py`。本轮不修改其逻辑，仅提供新的显式操作表，因此避免另写同功能脚本。
