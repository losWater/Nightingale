# 参数方案 0001：恢复词重目标前的量纲实验

## 已确认事实

C19 原配置没有 `words_full` 目标，词重完全未参与退火。

历史夜莺配置使用过：

```yaml
words_full:
  tiers:
  - top: 2000
    duplication: 150
  - top: 20000
    duplication: 40
  duplication: 15
  levels: []
```

这些数值只能作为历史参照，不能直接认定为 0.85 最优参数。C19 的三码和简码手感目标已经重做，目标函数量纲与旧版不同。

## 首轮建议

从同一个 C19 初始解做少量、同种子或配对种子的对照，不立即大规模抽卡：

1. `A0`：C19 原目标，验证续跑链路不会改变基准定义。
2. `A1`：只加入较弱的前 20000 词重权重。
3. `A2`：中等前 20000 词重权重。
4. `A3`：恢复历史的 2000 / 20000 / 全体三层权重。

先依据单位步数内各目标项的变化量校准“较弱 / 中等”，不能仅凭整数大小猜权重。

## 每张卡必须在对话中报告的核心指标

1. 前 6000 三码数与比例
2. 简化等效当量（简码手感）
3. 简码重码率
4. 全码重码率
5. 前 1500 有效全码重码数，并明确是否为 0
6. 前 20000 二字词重码表现
7. 前 20000 词与常用单字直接撞车数
8. 大跨排 / 小跨排
9. 第二—第三键左右手分离率（B=右手）

单指微移、小指联动、热力分布继续写入完整报告；出现明显恶化时必须在对话中升级提示。

## 第二—第三键分离率的定位

- 第一轮：强制测试，目标权重为 0。
- 若它在候选间有明显差异，且没有被现有手感指标充分解释：增加一组低权重入炉实验。
- 不允许为了单独抬高分离率，牺牲三码率、简码重码或常用区手感而不披露。
