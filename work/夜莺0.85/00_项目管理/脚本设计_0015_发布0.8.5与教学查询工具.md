# 脚本设计 0015：发布0.8.5与教学查询工具

## 目标

从已验收的C v5、G v1、最终G8C12布局和8105规范拆分表一次性生成 `releases/v0.8.5`，不得调用带0.7硬编码裁决的旧发布主生成器。

## 发布输入

- 正式单字接口C v5普通版、搜狗版及含快符搜狗版；
- 最终挂接字词接口G v1普通版、搜狗词库版及含快符版；
- G8C12最终优化配置；
- 夜莺根集、Chai部件名称解析资产；
- `最终规范拆分表_待核验.tsv`；
- `结构等价例外_待验收.yaml` 的展示层别名；
- F裁决、单字裁决和无理码记录。

## 输出

- 0.8.5单字普通版（`编码<TAB>字`）、搜狗单字版与搜狗单字含快符版；
- 0.8.5挂接字词版（无简词）及两个搜狗词库版；
- 0.8.5键位布局YAML；
- 字根练习TXT和HTML练习器；
- 拆分查码HTML：展示C v5全部单字码、候选位与8105规范拆分；
- 编码反查HTML：按最终G候选顺序返回某码对应的全部单字和词，并提供前缀家族浏览；
- 裁决记录快照、发布说明、SHA-256清单JSON。

## 门禁

1. 发布目录必须事先不存在；
2. 复制型码表必须与已验收源文件哈希一致；
3. 查码页必须覆盖C中的全部不同汉字，拆分记录必须来自8105规范表；
4. 字根练习必须覆盖当前布局全部主根；
5. 展示层将“孑”加入“子”的练习提示，但不得写回根集、拆分或Chai配置；
6. 所有HTML使用UTF-8并内嵌数据/字体，拆分查询可离线打开；
7. 输出清单记录所有发布文件哈希与上游输入哈希。
