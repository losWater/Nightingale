# 脚本设计 0008：第二届三十二强无人值守

## 赛制

- 16组，每组16张全新随机卡，共256张；
- 每组按五项核心指标等权秩和选前2，共32强；
- 五项：前6000三码数（高优）、普通简码组合当量（低优）、字词碰撞软分（低优）、简码重码率（低优）、前1500全码二三键换手率（高优）；
- 硬门禁：前300有效全码重码必须为0；
- 安全栏同分裁决：前1500有效全码重码、全码重码率、单指微移、小指联动；
- C19只作卫冕基准，不占32个新卡名额。

## 固定退火参数

- 字词碰撞权重0.1；
- 前6000三码奖励-90；
- 前6000单字全码换手权重0.25；
- 普通当量与换手当量隔离，B归右手；
- 每卡100000步。

## 无人值守与恢复

每组生成独立清单；完成退火后生成核心指标和附加手感，随后写出组内评分与出线名单。总状态在每组结束后原子更新。已有完整组跳过，残缺组停止并保留现场，不得用残缺数据排名。
