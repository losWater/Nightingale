# 脚本设计 0012：非常用字撞前20000词自动让位

## 目的

在接口E已经正确区分“直接撞车待审”和“简码已自动让词”的前提下，批量生成F阶段的自动裁决：同码全部单字均不属于前3527，且最高二字词排名不超过指定阈值时，让最高频二字词取得首选，原单字整体后移一个候选位置。

默认阈值为前20000词。

## 输入

1. G8C12 `编码审计明细.tsv`：以 `原始行号 <= 3527` 定义前3527 `(字, 实际码)` 身份；
2. E阶段 `字词相撞明细.tsv`；
3. E阶段综合字词审查表，用于取得码位当前完整、真实的候选顺序；
4. F阶段 `字词候选裁决.tsv`。

## 强制边界

- 只处理 `status=直接撞车待审`；
- 同码只要有一个“当前读音身份”位于前3527，整组不自动处理；不同读音不得因字形相同而共享前3527资格；
- 当前码能在审计表中精确匹配 `(字, 实际码)` 时按该身份排名判断；人工改码导致无法精确匹配时采取保守回退：只要该字任一身份在前3527，便留给人工审查；
- `two_top_rank` 必须存在且不超过阈值；
- 已经存在于F裁决表的码位一律跳过，不覆盖人工裁决；
- 每组只让出一个首选位置：最高频二字词移至首位，原单字保持相对顺序并整体后移，其余词保持原顺序；
- 调整前、调整后的候选均取自E综合表的完整码位，不得遗漏同码的保留全码字或其他词；
- 不修改C、D或E，只向F追加可审计的裁决行；
- 输出后校验裁决编号与码位唯一。

## 输出

更新后的 `字词候选裁决.tsv`，新增记录状态为 `规则自动让位：前3527外撞前N词`，理由中写明单字范围、最高词排名和规则阈值。

## 防回归意义

人工审查清单必须首先排除E阶段已经自动化解的保留全码；本脚本直接检查状态字段，避免再次发生把 `简码已自动让词` 混入F人工裁决的问题。
