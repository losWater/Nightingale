# 脚本设计0011：身份级字词表生成修复

## 目标

修复综合字词表把“同字另一读音有简码”误当成“当前读音已出简”的问题。正式单字表继续作为最终字码布局事实源，但候选层级必须由8454字音身份审计和人工路径覆写共同确定。

## 判定规则

对正式单字表中的每个 `(字, 码)`：

1. 若人工层级覆写表声明，则采用覆写；
2. 否则若该对是任一字音身份的实际码，则归为实际单字；
3. 否则若该对是出简身份的保留全码，则归为保留全码；
4. 否则拒绝生成，禁止猜测；
5. 同一 `(字, 码)` 同时对应实际码和另一身份的保留全码时，实际码优先。

合并顺序仍为：实际单字 → 首词 → 保留全码 → 其余词。

## 强制回归

- `尺/chi@iiii`必须是实际单字，不能被`尺/che@iei`跨读音影响；
- `尉/yu@yuiy`必须是实际单字，不能按另一个读音推断；
- 人工升降、无理码必须在层级覆写中逐项有来源；
- 正式表中任何无法追溯来源的字码对都使构建失败。
