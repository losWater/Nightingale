# 脚本设计 0019：编码反向查询器

## 目的

从最终挂接字词接口G生成离线反向查询页。用户输入编码后，查看该码对应的全部单字和词及其候选顺序；同时展示同前缀码位，便于检查整个编码家族。

## 输入

- `夜莺0.85_G8C12挂接版_无简词_v1.txt`：最终G普通表，格式为`字或词<TAB>编码`。

## 输出

- `夜莺码v0.8.5编码反查.html`：UTF-8离线HTML，内嵌正式G的全部编码数据，不依赖网络。

## 门禁

1. 每个非空输入行必须恰好两列，编码只允许1—4位小写字母；
2. 同码候选严格保持G中的行序，不重排、不去掉字或词；
3. 输出必须覆盖G的全部条目和全部不同码位；
4. 内嵌数据反读后，条目数、码位数及关键码位候选必须与输入一致；
5. 查询页只读，不反向修改码表。
