# 夜莺 0.85

夜莺 0.85 是从夜莺 0.8 的退火冠军 C19 独立分叉的参数实验线。

## 边界

- 初始布局：C19（G9-C11，seed 910011）的原始 Chai 解。
- 继承：根集、人工拆分、8454 字音身份与频率、编码规则、一简规则、C19 键位布局。
- 暂不继承：0.8 后续人工码位裁决、无理码、容错码、字词让位裁决。
- 0.8 正式成果冻结；0.85 不覆盖、不回写 0.8 文件。
- 不使用飞键；允许将来在成品阶段为个别字增加多重码，但多重码不参与本轮根布局退火。

## 0.85 的目标

在保住 C19 的三码率、简码手感与简码重码表现的基础上，重新让前 20000 二字词避重参与退火，观察能否显著减少后续人工字词裁决。

第二键—第三键左右手分离率作为强制测试指标；B 按右手计算。第一轮只观察，不进入目标函数。

## 目录

- `00_项目管理`：范围、进度、参数裁决与实验结论。
- `01_基线`：C19 的原始解与原始配置，只读基线。
- `02_参数实验`：每轮实验的配置、输出、报告和裁决。
