# 冓头根实装（P0027）

2026-09-04，批改冓字灵异问题引出：三横两竖部件（𠀎，U+2000E）立为主根，键位m（与廿/龷/甘家族团聚，主人明确选m弃"零变码的n"）。

## 覆盖
"一＋龷"相邻且后随冂/八/十/衣省者并为冓头：核心18字＋扩展72字（冓/塞寒赛寨搴褰蹇骞/華/襄/韋诸族）。
护栏排除2个嫌疑字：䜺（后随日）、㗷（后随贝，疑为口+賓结构），待人工看字形。

## 代价
- 首码n→m仅6字：冓（居鞲前，有简让全）、斠、遘、觏、覯、顜，余皆落空码。
- 遘三简gzn废除（主人裁决方案3），遘走全码gzmp（空码）。
