# 可继续拆分字根普查

以当前规范拆分重新计数；未修改根集、拆分或码表。候选拆法供讨论，不等于已经批准的容错方案，也未模拟重码。

统计口径：按拆分中的完整根名统计包含它的字，每字只计一次。主根不合并附属根或锚定根；同一根兼具主根与锚定身份时分别列出，不能叠加。核心与扩展按各自规范拆分表区分。

现有定义包含175项主根、236项附属条目、11项锚定条目，以上是定义条目数，不是互斥的字形总数。所有条目的使用范围见全部根使用范围.tsv。
