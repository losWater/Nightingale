# 工作区索引

`work/`保存仍需追溯或继续运行的工程现场，不是用户下载入口。当前正式发布请看`releases/v0.8.5/`。

|目录|状态|用途|
|---|---|---|
|`重开工程/`|活跃上游|0.8根集、规范拆分、Chai输入和布局搜索主链。|
|`夜莺0.85/`|活跃维护|G8C12人工裁决、正式主表构建、输入法挂接和实战修复。|
|`夜莺0.86/`|冻结实验|降低重码要求、提高部分手感权重的实验；已决定不取代0.8.5。|
|`v08/`|历史工程入口|0.8早期基础设施、问题台账和搜索设计。|
|`optimize/`|历史运行现场|早期优化输出，不是当前构建入口。|
|`repro_test/`|历史验证现场|早期复现检查。|

稳定维护命令统一从`pipelines/`进入。不要把新的通用脚本继续堆入工作区；新实验应包含说明、输入清单、结果摘要和明确状态。
