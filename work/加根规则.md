## 规则零：原位立根（2026-08-19 用户提出，总纲优先）
部件现行拆法的**首根所在键**即为默认落键。数学保证：新码 abxy 极大概率不变——x 位按构造恒等；y 位仅当部首横跨首末（字=声韵+整个部首，即单根字）时变为部首键，且仅一个字母、走双码。好处：零记忆成本、零码面扰动、老打法全兼容。
案例：⺮竹头立d（129字零变化，竹本体附属）、禾挂h、羊翻转z、条底同b、耂挂十t（12字零码变）。

**键内自洽理论（用户 2026-08-19 提出）**：一个键是自我解释的生态，两条生长机制——①**种子生长**：键内多根由最小根层层长出（h: 干→千→禾/于、冂→门→凵；t: 十→耂、戈→戋成；u: 氏→氐；z: 羊↔𰀁）；②**末笔归巢**：根的末笔画/末部件本身就是该键笔画根，键位由尾巴自我宣告（q: 卜且专韦予全员尾竖/点；t: 尤与戈系尾㇏；b: 真尾八——记"真在b"与记"八在b"是同一条记忆）。推论：根的记忆成本≈与同键锚点的推导距离，距离为零即白背——这是原位立根零成本的认知学解释；真正花预算的只有跨键无锚根（艮j母j等脚本择键户）。

**认知学基础：头尾不对称（用户 2026-08-19 悟出）**：首根是**加法认知**——部首在前，书写与学习都从它开始，是"看见即所得"的知觉单元，立根等于给已有单元发身份证；末根是**减法认知**——字尾与整体完形焊在一起，须先在脑中执行"去掉前部"才知"剩下了什么"。故：①首位部件立根收益天然高；②尾位立根仅当剩余部分本身是强完形（现成常用字/知名部首，如艮母及龰）；③减法剩下无名碎片的（如𠃓），归并到形近大根（→勿）或不动；④尾位"技术上成字但完形感弱"的（专韦予且）收益平平，默认不再增补。

**修正（用户 2026-08-19）**：尾位成字部件默认不立根——三码率零收益（三简只看首根）、显示可走多拆登记，而立根必然搅动本字（成字根双打新码）。立根资格留给头位部件与不成字部件；已立的专韦予且比出与保留（实害为零），真曾撤后复立@b（真尾与八同键、无b/n分叉，整体完形直觉胜出——完形与拆解同键时优先立整体根）。

**推论（用户 2026-08-19 提出）**：部件的中间笔画对首末取根透明——只要部件首笔画归属键=部件落键，无论中间夹多少笔画，立根都零码变。因此"首笔相同的多笔画部件"永远可以免费收编（例：耂=十+𠂇，中间𠂇不进码，耂@t 与 十@t 同键即零成本）。

**三选一权衡**：每个候选部件先摆原位基线，再比较付费选项——
① 原位立根：零成本基线
② 形似键：付码变，买认知记忆（如 乌→鸟d、龰→止g）
③ 脚本择键：付码变，买三简/零残留收益（如 礻→d、艮→j、氏→u）

## 规则一：形似归键
新部件若与现有根形似 → 落到形似根所在键。两种落法编码等价（Δ重码/Δ三码率相同），按相似程度选展示方式：
- 真像到能共用记忆 → 挂**附属形**（并入宿主，查码/练习归宿主名下）
- 只是有点像、需要防混 → **同键主根** + 对比标注（参照 口/囗、㇒/丿 惯例）

## 规则二：无所依部件 → 脚本择键
沿固定优先序遍历 25 键（p 永不落根），在候选键上做判定：

```
遍历顺序: j f h g u r y t m v n b k d i e c l s o w x a q z
```

即：食指区 → 中指区 → 无名/小指区；各区内 中排 → 上排 → 下排；从左往右。

### 重码判定（口述中）
1. **双码并存**：新根加入后，受影响字的旧拆法/旧码全保留（一字多拆型，非根搬家型），新拆法的码追加进入。推论：加根只增码不删码。
2. **全码重码是伪指标**：方案出简让全，全码永远保留，新全码撞码只是多个次选，不构成否决。
3. **真判据 = 简码空位命中**：看受影响字的新前缀（声韵+新根所在键）对应的简码位是否空着——空则该字白捡简码、三码率上涨；不空则无益也无害。脚本优化目标是空位命中，不是重码最小化。

### 空位判定算法（口述中）
设新根使字 W0 获得新拆法，新全码 = abxy：
- 三简位 abx **空** → 直接给 W0 加上 abx 三简 ✅
- abx **已被字 W1 占据** → 看 W1 的全码，分两支：
  - **分支1**：W1 全码 ≠ W0 全码（≠abxy）→ 看 W1 的全码自身是否与某字 W2 相重：
    - **W1 全码有重**（存在 W2 与之同码）→ W1 的三简本就是避重简码，**不可动**。W0 不抢位，只留新全码。（若 W0 的全码又恰与某 W3 相重——无解兜底，标记出来具体情况具体分析）
    - **W1 全码无重** → W1 的三简只是便利、非必须。再看 W0 的全码有无重码：
      - **W0 全码有重** → W0 拿简码位是刚需（避重）→ W0 直接上位，W1 让位（回退自己的无重全码）
      - **W0 全码也无重** → 两边都是便利需求 → **公平竞争，字频高者得**
  - **分支2**：W1 全码 = W0 全码（同为 abxy）→ **出简让全自动避重**：一方持三简 abx，持简码者在全码位让全，另一方顶 abxy 首选——两字各得无冲突打法（3键 vs 4键首选）。简码归属交给既有的字频竞争机制（频高者持简码），两种归属都无冲突，生成器重跑自动落定。

### 停键判据
沿 jfhg… 顺序逐键评估（每键把受影响字全部过一遍空位判定树）：
- 某键能实现**零残留重码**（所有受影响字都拿到无冲突打法：空位命中 / 让全消解 / 刚需上位，且无"无解兜底"）→ **立即停**。遍历序本身就是指法优先序，先命中即最优。
- 所有键都做不到零残留 → 取**重码比重最小**的键（残留冲突按字频加权衡量）。

### 已定的评估指标序（定稿期通用）
① Δ重码（前6000，变差即否决）② Δ三码率 ③ 直观性/换码成本
（注：加根场景下①退化为"残留重码比重"，见上；全码撞码不计，见重码判定第2条）

### 主码选位细则（乌案例发现）
双码并存时主码的选择影响简码竞争前缀（生成器按主码前缀分桶）。规则：**已持简码的字，旧码保持主位，新码追加为副码**——避免主码切换导致三简前缀迁移、在新前缀上竞争失败而白丢现有简码（例：乌若以 wudd 为主，wud 上的舞更高频，乌将丢掉 wux 三简）。新码设为主位仅当它能赢得新简码或消解重码（例：重 vshz 为主）。

## 正字法裁定：点捺之辨（2026-08-19，用户裁定，虎码先例）
点(4/q) 与 捺(㇏/t) 界限本软，虎码干脆合并为一根。夜莺码维持现状惯例、**不作为错拆**：
- 首笔长点一律归 ㇏(t)：之永良学兴举觉必州义朗郎誉昶、礻家族等（数据核实：点q 首位为 0 字，惯例全局一致）
- 龰 尾按 4(q)、母/术尾按 ㇏(t) 等历史归并维持不动
- 立根后（礻/龰/母/氐/末）大部分高频暴露面已被整根覆盖，残余打点捺的字照惯例
- **点捺容错层（方案b，2026-08-19 试算通过）**：模糊件 q/t 通打——首位长点组 23 字补 q 位副码（之学永良兴举必州义等），龰族尾捺组 44 字补 t 尾副码（是走提定楚疑等）。试算：67 条容错码全部清洁落位（仅零频字/有简码字排二），前6000重码零变化。容错码为副码不参与简码竞争，不进多拆登记显示，正字法口径"点捺模糊件两键通打"

## 词占位复核口径（2026-08-19 复核后定）
- 空位/占位判定**以字词总表为准**（`夜莺码v0.3.1字词总表.txt`，全量无上限）；留位版只是搜狗特化产物，不作裁决依据
- 四码位上字 vs 二字词的优先级维持既有三指标法（简单鹤作者口径一致）：①字常不常用 ②字是否经常脱离词组独立存在 ③冲突词常不常用。字常用但基本随词组固定出现（如饕餮二字）→ 让位；否则字频 vs 词频对决，字高不让、词高则让（即 standalone(c) ≥ code_wmax 的保护字测试，make_words/make_liuwei 已实现）

### 层级细则（礻案例发现，用户 2026-08-19 确认为正式规则）
**扩展字永远队尾，可无脑被让位**：扩展字（tier 9）在任何码位判定中不构成阻挡、不参与竞争，基础字进场一律排它前面。备胎（有简码字的全码）排无简码字之后。判定"占用/刚需"时用 (层级, 频率) 排序后看本字是否居首——忽略层级会虚报冲突（例：祉新码 vidg 上的䇛是扩展字，祉进场即首选，并无"祉挤知"问题）。
