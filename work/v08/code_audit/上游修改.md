## libchai：13个修改文件

| 文件 | 我们增加/修改的功能 | 何时使用 | 主要审计风险 |
|---|---|---|---|
| `src/config.rs` | 新增字词交叉、五码辅助、分层字频加权指法、音型过渡当量及有效全码重码配置；可编码对象排序字段 | 解析夜莺扩展目标 | serde默认值、旧配置兼容、字段缺失行为 |
| `src/lib.rs` | 可编码对象新增`排序序号`，允许优化内部顺序与真实频率分离 | 自定义简码竞争顺序和保护层 | 一旦任意对象有序号，未编号对象排序行为；多音条目顺序 |
| `src/encoders/mod.rs` | 编码器接口新增“本次变化词”查询 | 增量目标缓存更新 | trait调用方是否全部实现、None语义 |
| `src/encoders/default.rs` | 在简码输出后收集全码或简码实际变化对象，覆盖间接依赖 | 每一步增量退火 | 防止仅简码易主时交叉缓存漏刷；三字专项测试覆盖 |
| `src/objectives/cache.rs` | 新增分层字频加权指法、音型过渡当量及有效全码重码；有效重码缓存跟踪上一步简码保护状态 | 0.8简码手感与实战重码目标 | 增减对称性、保护状态变化、编码端序、零分母、量纲和权重定标 |
| `src/objectives/default.rs` | 实现字词交叉碰撞、五码辅助；修复首次全量缓存；识别一二简保护并传入有效全码重码缓存 | 目标函数每次计算 | 增量/全量一致性、索引边界、简码长度、首型提取、多音及候选口径 |
| `src/objectives/metric.rs` | 输出交叉碰撞、辅助码、加权分层指法、音型过渡当量及有效全码重码 | metric报告 | 指标名称与实际归一化口径必须一致 |
| `src/operators/default.rs` | 实现并接通单根移动、双根交换、整键交换三种搜索邻域及比例校验 | 每一步退火变异 | 条件安排合法性、整键替换范围、空变化率、配置是否真正消费 |
| `src/interfaces/web.rs` | Web优化入口将`search_method`传入操作器 | 图形界面启动退火 | 前端显示比例与后端执行必须一致 |
| `src/interfaces/server.rs` | Server优化入口将`search_method`传入操作器 | HTTP服务启动退火 | 服务端与CLI/Web口径一致 |
| `src/interfaces/command_line.rs` | checkpoint写入成功后只保留最新一份，防止磁盘爆满 | 长跑退火 | 删除范围是否只限当前worker；中断恢复安全性 |
| `src/main.rs` | resume时从输入配置恢复checkpoint省略的decision space | 断点续跑 | 恢复的mapping_space与旧checkpoint是否同源 |
| `src/optimizers/simulated_annealing.rs` | 结束时对最佳解做完整重算，覆盖潜在缓存误差 | 每次退火收尾 | 最佳解/当前解混淆；报告与输出mapping一致性 |

当前补丁已在 `repos/libchai` 独立提交为 `eaa3d2d`；这里是0.8最需要独立审计和回归测试的代码层。
