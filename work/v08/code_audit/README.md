# 夜莺代码审计入口

本目录供独立审计者（Claude）使用。审计顺序：

1. `代码目录.md`：夜莺新增/修改脚本的职责、使用阶段和写入权限。
2. `上游修改.md`：对 libchai 与 hanzi-chai 的改动及原版地址。
3. `../问题台账.yaml`：已经发现的 Bug 和风险。
4. `../退火参数审计.md`：本轮目标函数口径与正式运行门禁。
5. 具体实验的 `../experiments/<ID>/manifest.yaml`。

第一轮独立审计原文为 `claude_审计报告_2026-08-27.md`，夜莺侧编号映射和处置见 `审计接收与处置_2026-08-27.md`。

## 审计范围口径

- 主仓以 `cafc3b3`（夜莺B进入大规模退火/词位实验前的主线提交）为历史比较点。
- 同时收录当前工作区所有新增或修改的 Python 脚本。
- `repos/libchai`、`repos/webchai` 是独立上游 Git 仓库，修改单独列出。
- `releases/` 中的 HTML、码表和图片是生成物，不作为手写源码；应审生成器和一致性测试。
- 目录描述的是“我们新增或改动过的代码”，不声称项目里未列出的历史脚本都由当前开发过程编写。

## 审计反馈格式

建议每项反馈包含：文件、行号、严重度、现象、可触发输入、预期影响、建议测试。确认后写入 `../问题台账.yaml`，分配稳定 `BUG/RISK` 编号。
