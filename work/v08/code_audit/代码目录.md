# 夜莺新增与修改代码目录

状态含义：

- **生产**：发布或正式实验链仍会使用，必须重点审计。
- **审计**：只读分析/验收工具，不应修改上游或正式资产。
- **实验**：构造或运行历史实验；0.8使用前必须迁移到manifest规范。
- **历史**：服务夜莺B选根或0.7，不得直接接管0.8。
- **待整改**：已知存在溯源或原地修改风险，整改前不得用于0.8正式实验。
