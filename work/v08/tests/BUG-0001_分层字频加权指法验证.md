# BUG-0001：分层字频加权指法

日期：2026-08-27

状态：实现已验证，参数权重尚未定标。

## 设计裁决

不改变历史 `tiers.fingering` 的按字计数语义；新增 `tiers.weighted_fingering`：

- 每个指法事件乘对象频率累计。
- 用该层的加权键对总量归一化，得到0到1附近的事件率，而不是拿字频总量除以字数。
- 报告明确使用“加权同手／加权大跨……”名称。
- 旧配置缺少新字段时仍按原语义解析、运行和输出。

这使0.8可以明确选择“常用字手感优先”，同时不伪造历史实验的参数含义。

## 测试

Rust方向测试使用相同指法事件、频率100与10的两个对象：高频贡献严格为低频的10倍；撤销贡献等于原贡献的相反数。

## 后续边界

本项只证明指标实现和方向正确，不在这里拍脑袋确定权重。300／500／1500各层的目标值与权重必须通过参数扫描和对照布局定标；在此之前不得声称手感目标已经调优。
