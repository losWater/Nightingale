# BUG-0008：运行目录不可变与manifest验证

## 原问题

旧 `run_final_protection.py` 直接修改源实验的 `input_config.yaml`，并覆盖 `stdout.log`、`stderr.log`。二次运行后原始参数与旧日志不可恢复，结果无法独立复现。

## 修复

- 源实验目录只读；新接口强制提供 `--output-run`。
- 输出目录必须不存在，拒绝覆盖旧配置、日志或结果。
- 参数只写入新目录的实际运行配置。
- manifest记录源目录、参数、完整命令、UTC时间和运行状态。
- 对源配置、实际配置、elements、引擎、键位分布及组合当量资产记录SHA-256。
- 状态依次记录 `prepared/running/complete`；非零返回或异常记录为 `failed`。
- stdout/stderr使用排他创建模式。

## 验证

5项专项测试通过：源配置哈希不变、实际参数正确、六类输入哈希与命令齐备、已有输出拒绝覆盖、坏参数和缺资产不创建目录。

使用历史保护实验做1步1线程真实短跑，源配置前后SHA-256均为 `C99B372CD1F9F9B09AB09C201E97DA93D9840A33D73201069BE8E9C8E621C7E1`；manifest最终状态为`complete`，引擎运行成功。

相关合并回归52项全部通过。该脚本的历史目标参数仍不属于0.8正式实验；本次验证的是不可变运行与溯源机制。
