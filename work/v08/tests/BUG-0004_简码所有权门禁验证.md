# BUG-0004：简码所有权门禁验证

## 原问题

旧 `audit_final_short_codes.py` 只正向核对显式一／二简的长度；名单外对象反向抢位、自动三码赢家均不可见，并以 `(字, 音码)` 字典保存结果，导致同字多码互相覆盖。

## 修复

- 以资产行号作为稳定身份，逐行保留同字、多音和多形码。
- 建立逻辑简码位到全部资产行的反向索引。
- 独立复刻libchai分配顺序：先全码空间，再显式简码，再按内部排序分配常规三码。
- 同时支持结构化 `encoder.short_code` 与历史兼容配置；多处规则冲突时失败。
- 正确处理频率／显式排序序号、自然三码占位，以及 `count` 缺省为1。
- 坏行、行数不等、资产错位、非法规则均响亮失败；发现所有权差异时命令返回非零。

## 验证

10项最小测试通过，覆盖反向抢二简、三码赢家、自然三码容量、同字多码、两种排序、三种配置入口冲突和坏输入。

release引擎现场生成完整码表后独立复算：8455行；一简26、二简405、三码4082、全码3942；所有权差异0。详见 `BUG-0004_完整资产审计.md`。

与字词交叉、多音频率、读音排序和新手感指标合并回归共32项，全部通过。
