# BUG-0007：随机起点条件约束验证

## 原问题

旧 `build_random_layout_seed.py` 先随机无条件元素、再单次处理条件元素。条件引用另一个尚未随机化或随后改变的元素时，会读取模板旧值；生成结束也不复查。单选元素沿用旧mapping，未知操作符被静默放行，缺省seed不可复现。

## 修复

- 从全部mapping_space候选建立条件依赖图，被引用元素先求值。
- 依赖环、未知引用、未知操作符、空候选和畸形候选全部失败。
- 使用随机化回溯；上游随机选择令下游无解时自动撤销，而非产出非法布局。
- 单选和多选元素都从本轮候选空间落实，空间内模板旧值先移除。
- 求解结束后逐元素验证最终值属于候选空间且条件成立。
- `--seed` 改为必填；输出配置写入 `experiment.random_seed`。
- `generated_mapping_space` 与旧路径同时存在但内容冲突时拒绝运行。

## 验证

8项专项测试通过，其中三元素依赖链连续验证1000个seed；另覆盖回溯恢复、循环依赖、未知操作符／引用、单选旧值、无解空间及同seed复现。

完整夜莺资产包含474个空间元素，当前没有条件候选。seed=777两次生成文件SHA-256均为 `174EE399E66FC0E9E67793FCBAA6C4B9FC5B2E55DA054F74209D961CD6F9CBEC`，release引擎成功读取并生成码表。条件传播本身由上述合成约束测试验证，不能把“当前资产无条件”误写成真实条件资产验收。

相关合并回归47项全部通过。
