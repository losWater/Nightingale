# EXP-20260827-06：分层三码＋简码跨排第一轮

## 目标与权重

- 累计三码层：前300/500/1500各-15，前6000为-70。
- 简码加权大跨：前300/500/1500各100。
- 简码加权小跨：前300/500/1500各20。
- 其余目标为0；大跨惩罚为小跨5倍。
- 自动测温后，4条独立链各跑20000步。

## 结论

1. 四条链均超过3690参照值，说明加入简码跨排目标后仍有充足三码余量。
2. 前300四链大跨均为0；线程0—2的小跨均为7.34%，显著优于基线8.82%。
3. 线程2是当前目标函数总分最优；线程1在前1500三码数和小跨上更好。二者构成有意义的Pareto候选，暂不按单一总分淘汰。
4. `bc`样例并未固定收敛到某几个字母：线程0—3的“保/宝”分别为`bcp/bcw`、`bci/bca`、`bcm/bci`、`bcf/bcp`。这不否定总体指标改善，但下一步必须输出具体坏键对贡献，确认平均值没有掩盖少数高频坏字。
5. 本轮仅2万步，属于权重方向验证；不能直接作为0.8候选布局。

## 具体坏键对与热力复审

- 前300大跨：线程1、2均为0；基线的主要来源是“由`yzq`”和“近`jbr`”。
- 前500大跨：线程1主要剩`vr/mu/qz/tv`，线程2主要剩`vr/um/mu/tv`；单项均不超过0.08%。
- 前1500大跨：线程1主要为`mu/vr/qz/tv`，线程2主要为`mu/vr/tv/um`，未发现单个高频字吞掉平均值。
- 小跨的最大来源长期是固定音码键对`yu/uh/dc/nm`，对应“与/于、上、到、年”等字。这部分根键排列不可改变，会稀释可优化手感的报告值；后续宜增加只统计“音末→首根”的专项指法指标。
