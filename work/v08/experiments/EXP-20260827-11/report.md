# EXP-20260827-11：两组权重的12链重复性验证

> 2026-08-27完整性复验：旧结论只完成局部目标比较。新版Chai已对基线、v1-3794和v2-3797重新编码，完整统一报告见`full_metrics_report.md`；三者字段契约通过，但因目标函数不同，总分不可横比。两候选均新增1组前300全码重码，尚不能据旧总分直接晋级正式候选。
