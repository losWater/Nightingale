# 夜莺码加根方法论（v0.4 定稿版）

> 2026-08-19 随 v0.4「字根定稿版」沉淀。一套在**布局冻结、不重跑退火**前提下持续补直观字根的完整方法：测评层给账本，认知层给理由，工程层给保障。实战案例三十余宗，全程零退火、零布局变动。

## 〇、总纲：原位立根

**部件现行拆法的首根所在键，即为该部件的默认落键。**

数学保证：设字的旧码为 `声a 韵b 首x 末y`，部件立根后新码极大概率仍为 `abxy`——
- x 位按构造恒等（部件落在自己首笔画的键上）；
- y 位仅当部件横跨首末（字＝声韵＋整个部件，即单根字）时才变为部件键，且只变一个字母、走双码并存。

**推论（中间笔画透明）**：首末取根制下，部件中间夹多少笔画都不进码。因此"首笔归属键＝落键"的多笔画部件永远可以免费收编（例：耂＝十＋𠂇，中间 𠂇 不进码，耂 与 十 同键 t 即零成本；民 首折尾折双锚 o，全族补码为零）。

## 一、三选一权衡

每个候选部件先摆原位基线，再比较付费选项：

| 选项 | 成本 | 买到什么 | 案例 |
|---|---|---|---|
| ① 原位立根 | 零 | 拆分直观化 | ⺮竹头d（129字零变）、禾h、羊z、民o、耳n、卜q |
| ② 形似键 | 家族双码 | 认知记忆钩 | 乌→鸟d、龰→止g、氺→水o、凵→冂h（框族）、已→巴v（己已巳团圆） |
| ③ 脚本择键 | 家族双码 | 三简收益/零残留 | 礻→d（+7三简）、艮→j、氏→u |

择键遍历序（脚本用）：`j f h g u r y t m v n b k d i e c l s o w x a q z`（食指→中指→小指区，各区中排→上排→下排）。

## 二、空位判定树（新码落位）

设新码 abxy：

```
三简位 abx 空 → 直取 ✅
abx 被 W1 占 →
 ├ W1 全码有重（基础字层）→ W1 是避重简码，不可动；W0 只留全码
 ├ W1 全码无重（便利户）→
 │   ├ W0 全码有重 → 刚需上位，W1 让位回全码首选
 │   └ 双方均无重 → 拼字频，高者得
 └ W1 与 W0 全码同为 abxy → 出简让全自动避重（一方持简码，另一方顶全码首选）
```

**配套铁律**：
- 全码重码是伪指标（出简让全，重了只是次选）；真判据是简码空位命中。
- 扩展字永远队尾、无脑让位，不构成占用。
- 码位占用判定必须带层级 (tier, 频率) 排序——忽略层级会虚报冲突。
- 空位与占用**以字词总表为准**（含词全量）；字 vs 词按三指标法（①字常用度 ②是否脱离词组独立存在 ③冲突词常用度），即保护字测试 standalone(c) ≥ code_wmax。

## 三、双码三分法（改动的旧码处置）

1. **一字多拆**（两种拆法在现有字根下都成立，如 重＝千日垂土/平撇拆）→ 双码并存，旧拆保留为容错码，多拆登记表记录、查码页双拆展示。
2. **根搬家/挂靠迁移**（旧码指向已不存在的根位置，如 于 v→h）→ 旧码全部清除，绝不留幽灵码。
3. **错拆 bug** → 直接废除旧码。

**主码保位细则**：已持简码的字，旧码保持主位、新码只作副码（防止三简前缀迁移导致白丢简码）；新码设主位仅当它能赢得新简码或消解重码。

## 四、认知层双理论

**头尾不对称**：首根是加法认知（部首在前，书写学习从它起步，"看见即所得"）；末根是减法认知（字尾与整体完形焊死，须先脑内去掉前部才知"剩下什么"）。故：首位部件优先收；尾位部件仅当剩余部分是强完形（艮母及龰）才立根；无名碎片归并形近大根（𠃓→勿、衣底𧘇→衣）；技术性成字但完形弱的（专韦予且）不再增补；**完形与拆解同键时优先立整体根**（真＝直＋八 与 八 同键 b，记"真在b"一步到位）。

**键内自洽**：一个键是自我解释的生态。①种子生长：键内多根由最小根层层长出（干→千→禾/于；冂→门→凵）；②末笔归巢：根的末笔画就是该键笔画根，键位由尾巴自我宣告（q 的卜且专韦予全员尾竖/点；出随山走 m）。根的记忆成本≈与同键锚点的推导距离，零距离即白背——这是原位立根零成本的认知学解释。

## 五、简码层机制（v0.4 新增）

- **副读音三简补位**：多音字非主读音的空置三简按字频授予（地dez、重iso 等 112 个）。
- **副读音简码竞争**：占位者为便利户且频≤5万、挑战者 3 倍频差 → 自动夺位（都dut 等 69 个）；>5万 持有者一律人工逐案（乐yto/佛fus 特批，的/大/给 否决）。
- **御旨层**：美学盖过频率的钦定简码（才彩采声母梯田：c/cd/cdw）与御旨副简码（心xbh 跨手位），生成器 FORCED / FORCED_EXTRA 一行落位，竞争层自动绕行。
- **副读音简码不触发让全**：主读音全码待遇不受牵连。

## 六、工程保障

- `scripts/sync_readings.py`：拆分↔码表全量对账（按现行拆分算应有码，缺则补）。
- `scripts/root_census.py`：字根就业普查（真幽灵/门面根/个位数户/只进中部），每次动根后体检。
- `scripts/propose_root.py`：择键遍历评估器。
- 一字多拆补丁按**部件**发放而非按字（耂 案教训：给者发待遇时就该查全族户口）。
- 变体根独苗检测：一个变体只服务一两个字就并入正根，服务一片才单独立形。
