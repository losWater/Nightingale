# 夜莺 0.4 旧生产线

这里完整保留已经废弃的 0.4 方案生产线及其根目录资产，便于追溯历史，不再参与当前版本生成。

- `scripts/`：0.4 及更早版本的生成、制图和导出脚本。
- `root-assets/`：旧词库、补码、备用码、截图、问题记录和交接材料。
- 对应发布包位于 `../releases/v0.4/`。

当前正式版是 0.8.5。请从仓库根目录 `README.md` 和 `releases/v0.8.5/README.md` 进入；跨版本仍有效的设计原理已提炼到 `docs/principles/`。

归档采用移动而非删除，因此历史内容仍可恢复和核查。但旧脚本包含固定的 `releases/v0.4` 路径，不能当作当前生成链运行。
