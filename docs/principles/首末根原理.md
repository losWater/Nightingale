# 首末根原理

首末根原理是夜莺码跨版本延续的核心取形原则，不属于0.4、0.7或0.8.5任一具体键位布局。

## 编码形式

夜莺单字全码写作：

```text
abxy = 双拼音码 ab + 首根 x + 末根 y
```

- `ab`是读音对应的小鹤双拼音码；
- `x`是规范拆分中从字首取得的根；
- `y`是规范拆分中从字尾取得的根；
- 中间部件用于保证拆分结构正确，但通常不直接出现在最终四码中。

## 核心判断

若一个字的规范拆分为`x + 若干中间部件 + y`，码表层最终只保留首根`x`和末根`y`。由此得到以下规则：

1. 只改变中间部件、不改变首末根的方案，不会改变该字全码。
2. 判断是否值得新增字根，必须检查它能否改变真实首根或末根，不能只看部件是否完整、醒目。
3. 判断末根应从字尾向前观察，寻找规范拆分中最后一个可见根。
4. 一个整字根与它的自然拆分若产生相同首末根，则二者码面等价；在不增加有效区分时，优先选择更少记忆、更一致的根集。
5. 首末码面等价不表示中间拆分可以任意处理。完整拆分仍须符合字形结构、笔画边界和人眼直觉。
6. 新增、合并或锚定一个根时，要检查全部直接用户、嵌套用户和多音字，不能只检查最初发现它的单个字或音节。

## 简码与全码评价

### 三码

同一音节内，除去已经取得二简的字，其余字按首根竞争三码`abx`。同一首根组通常只有最高频字取得三码，其余字使用全码。

因此，调整根集时不仅要看重码总数，还要看哪些字获得或失去三码，以及这种变化是否符合实际频率和手感。

### 全码

只有读音相同且首根、末根都相同的字，才构成理论全码重码。评估修改时必须区分原有重码与新增重码，并优先保护常用字。

## 与字架的关系

字架负责表达“外层共同形成一个架子、中间容纳其他部件”的结构。字架进入规范拆分后，仍然服从首末根原理：字架或其宿主承担首根，架内末端部件决定末根。

夜莺的字架思路受虎码字架方案启发；夜莺所做的是结合自身根集和拆分体系逐字适配，不把字架概念视为夜莺原创。

## 原理与具体版本

键位布局、根的数量、简码归属和人工裁决都可能随版本变化；首末根原理作为判断方法保留。废弃旧版本时，应淘汰旧码表和旧键位结论，但保留仍然成立的原理、术语来源和审计方法。
