# 夜莺 0.9.1 真源清单

本页回答一个维护时最容易混乱的问题：改动应该落在哪里，哪些文件只是生成结果。

同一份映射的机器可读版本位于`schema/v0.9.1/manifest.yaml`；正式派生物统一通过`pipelines/v09/rebuild.py`重建。

## 仍待收口的重复资产

`夜莺B/work/根集.yaml` 与当前根集内容暂时一致，但它属于选根阶段历史来源；现阶段保留用于追溯。后续应让构建链只读一个规范路径，再将另一份改为自动镜像或历史快照。

同理，`work/重开工程` 与 `work/夜莺0.85` 仍混合了源码、实验现场和生成结果。这次重构先建立边界，不在没有回归验证的情况下批量迁移这些活跃路径。

## 修改规则

1. 原理改动写入 `docs/principles/`，不要埋在某次实验日志里。
2. 根、拆分和字架改上游真源；码表的实战无理码与候选调整走裁决表。
3. 单字表和字词表是发布主表；搜狗、手心、查询器和练习器统一重建。
4. 生成后运行完整性检查，并确认脚本没有重新写回旧路径。
5. 历史方案只进入 `archive/`，不再回到仓库首页或当前发布入口。
