# 仓库架构

当前真源对应关系见[真源清单](真源清单.md)，分阶段迁移计划见[重构路线图](重构路线图.md)。

夜莺仓库按“长期原理、当前真源、生成程序、应用源码、正式发布、历史归档”分层。

```text
docs/       跨版本文档
schema/     当前方案的唯一真源
pipelines/  生成、审计和发布程序
apps/       查询器与练习器源码
tests/      自动校验与发布门禁
releases/   当前正式发布
archive/    废弃版本和历史研究
external/   外部数据来源说明，不直接作为夜莺真源
```

## 数据流

```text
根集 + 规范拆分 + 读音 + 人工裁决
                 ↓
            两张正式主表
                 ↓
 搜狗 / 手心 / 查询工具 / 练习工具 / 发布清单
```

任何派生文件都不得反向成为真源。实战微调只写入正式主表和对应裁决记录，然后统一重建派生物。

## 当前迁移状态

0.9仍有一部分真源和脚本位于`work/重开工程`及`work/夜莺0.85`。重构期间先建立映射和校验，再分批迁入`schema`与`pipelines`；迁移完成前不得删除旧路径。
