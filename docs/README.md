# 夜莺码文档中心

这里保存跨版本仍然有效的原理、使用说明和开发维护文档。

- `principles/`：不随某一版键位淘汰的设计原理。
- `user-guide/`：当前正式版的安装、练习与使用说明。
- `maintainer-guide/`：真源、生成链、测试和发布流程。
- `research/`：论文、测评方法和外部研究资料。
- `credits/`：外部方案、数据与工具的来源和致谢。

版本专属说明仍随发布包存放在 `releases/v0.9.1/`。历史方案的说明只在 `archive/` 中保留，不作为当前入口。

维护当前方案时，先读 `maintainer-guide/真源清单.md`，避免直接修改派生码表。

目前已经独立整理的跨版本原理包括：

- `principles/首末根原理.md`
- `principles/选词原理.md`
