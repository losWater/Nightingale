## Windows Rime 三版本补发 · 2026-09-30

**只建议使用 V5 版本。V5 模型：强烈推荐。**

Windows 用户请使用下列小狼毫包；此前的 `mac-*` 包只适用于鼠须管。Windows 包面向 **Windows x64 + 官方小狼毫 0.17.4**，不能与 Mac 包混装。V5 原生库不支持 32 位宿主；其他宿主版本须另外验证。

- [Windows V5 版（强烈推荐）](https://github.com/losWater/Nightingale/releases/download/v2.5/Nightingale-Rime-2.5-windows-v5-20260930.zip)：本地整句模型与夜莺固定码序。
- [Windows 形码版](https://github.com/losWater/Nightingale/releases/download/v2.5/Nightingale-Rime-2.5-windows-shape-20260930.zip)：无模型，最大四码、五码顶屏。
- [Windows 形码单字版](https://github.com/losWater/Nightingale/releases/download/v2.5/Nightingale-Rime-2.5-windows-single-20260930.zip)：单字与夜莺快符，手动确认上屏。
- [Windows SHA256 校验值](https://github.com/losWater/Nightingale/releases/download/v2.5/SHA256SUMS-windows-20260930.txt)。
- [Windows 引擎验证报告](https://github.com/losWater/Nightingale/releases/download/v2.5/windows-verification.json)。

安装前从小狼毫菜单打开用户文件夹并完整备份。按包内 README 合并文件、方案列表和横排候选补丁；不替换个人词库或学习记录。更新 V5 DLL 后须退出并重启小狼毫算法服务，再重新部署。

魔虎原作者 **fcxxxz**，项目 https://github.com/fcxxxz/rime-mohu 。V5 模型、原生引擎及相关 Lua 为魔虎原作，不是夜莺原创；原作者声明、模型说明和 GPL v3 许可证保留在包内 attribution/ 与 LICENSE-mohu。
