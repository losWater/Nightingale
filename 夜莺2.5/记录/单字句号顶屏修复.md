# 单字版句号顶屏 · 2026-09-27

用户提供可操作的触发方式：字母编码未上屏时按句号，期望像逗号一样先提交候选，如 f. → 发。。

## 发现与修改

本机编译配置继承了默认 `period → Page_Down (has_menu)`；recognizer 同时继承包含 `^[a-z]+[.].+$` 的 URL 规则。旧版引擎测试 f. 仍停留 f，不提交发。，f, 则正常提交发，。包含点的序列可被识别成英文 URL；旧序列 r.j 曾出现保留 r.j 的结果。不能将所有偶发点问题都直接归因于本次机制，也没有证据证明先前关闭的系统双空格替换就是根因。

新增 `tools/rime_mac/src/yeying25_single_period.lua`，只用于单字版。在 recognizer/key_binder 之前处理普通句号键：

- 中文状态、小写1至4码、当前有候选：提交当前选中的候选，然后输出 。；ascii_punct 开启时输出英文点。
- 不是盲取第一候选，保留当前选重和简繁过滤结果。
- 放行快捷键修饰键、英文模式、长英文串、URL、反查、空输入和无候选情况，由原逻辑继续处理。
- 仅更新单字版，不修改形码/V5、英文保护、码表、快符或模型。

构建脚本写入新处理器，方案版本升为 2.5-single.6。真实输入法仅新增一个 Lua 文件、在 schema 插入处理器并更新版本，不整包覆盖。原 schema 备份于 `备份/单字句号-rrbOEl/`。新 Lua SHA-256：d77538c435d2c820aa794c23b5eb54090a5eb07a6b9d5b77cd40e410eeda97ff。
