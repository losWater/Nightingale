# 夜莺码

夜莺码是一套“小鹤双拼音码 + 首末字根形码”的音形输入方案。

- 当前最新版本：**0.8.5（半定稿）**

- 发布目录：`releases/v0.8.5/`，发布清单状态为 `pass`
- 当前任务：导入实打、收集问题；若无新问题，冻结0.8.5。不再默认回到早期0.8布局搜索。
