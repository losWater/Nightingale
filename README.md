# 夜莺码

夜莺码是一套“小鹤双拼音码＋首末字根形码”的音形输入方案。

当前正式版本为 **0.8.5（半定稿）**，采用 **G8C12** 键位布局。目前进入实打校正阶段：主要调整常用字简码、容错码和候选顺序，不再默认回到早期方案重新选根或重跑布局。

## 下载与使用

正式发布包位于 [`releases/v0.8.5`](releases/v0.8.5/README.md)：

- [`01_正式码表`](releases/v0.8.5/01_正式码表/)：单字表、综合字词表和配套数据；
- [`02_输入法挂接`](releases/v0.8.5/02_输入法挂接/)：搜狗与手心可导入文件；
- [`03_字根与拆分`](releases/v0.8.5/03_字根与拆分/)：字根表、规范拆分和字架说明；
- [`04_查询与练习`](releases/v0.8.5/04_查询与练习/)：编码反查、拆分查询、部件查字及练习工具。

第一次接触夜莺，建议先查看字根表，再使用字根练习和必拆字练习。

## 编码原理

夜莺单字全码写作：

```text
abxy = 双拼音码 ab + 首根 x + 末根 y
```

完整说明见：[首末根原理](docs/principles/首末根原理.md)与[选词原理](docs/principles/选词原理.md)。

字架思路受虎码字架方案启发。夜莺结合自己的根集和规范拆分进行了逐字适配，不将字架概念视为夜莺原创。详见：[0.8.5字架说明](releases/v0.8.5/03_字根与拆分/夜莺码v0.8.5字架说明.txt)。

## 历史版本

0.1—0.7及0.4等已经废弃的方案保存在[`archive/releases`](archive/releases/)。它们用于追溯设计过程，不代表当前夜莺，也不建议新用户安装。

历史版本中仍然有效的设计思想会提炼到`docs/principles`；具体旧键位、旧根集、旧码表和阶段性结论继续留在归档中。
