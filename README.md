# 夜莺码

夜莺码是一套“小鹤双拼音码＋首末字根形码”的音形输入方案。

当前正式版本为 **0.9.1**，采用 **G8C12** 键位布局。0.9 在 0.8.5 半定稿基础上经实打校正与群友地毯式批改而来：新立耒、业、𠀎、党字头、龰等根，八个繁体根对齐简体码位，拆分正名数百字，并确立"有简让全""一词次选"等候选序判例。更新日志见 [`releases/v0.9/夜莺码v0.9更新日志.txt`](releases/v0.9/夜莺码v0.9更新日志.txt)；0.8.5 半定稿原貌归档于 `archive/releases/v0.8.5半定稿快照/`。

0.9.1 是维护版，新增利族／居族共53条全码容错，调整方放等简码并修正戍族拆分。详见[0.9.1更新日志](releases/v0.9/夜莺码v0.9.1更新日志.txt)。

## 下载与使用

正式发布包位于 [`releases/v0.9`](releases/v0.9/README.md)：

- [`01_正式码表`](releases/v0.9/01_正式码表/)：单字表、综合字词表和配套数据；
- [`02_输入法挂接`](releases/v0.9/02_输入法挂接/)：搜狗、手心与冰凌可导入文件；
- [`03_字根与拆分`](releases/v0.9/03_字根与拆分/)：字根表、规范拆分和字架说明；
- [`04_查询与练习`](releases/v0.9/04_查询与练习/)：编码反查、拆分查询、部件查字及练习工具。

第一次接触夜莺，建议先查看字根表，再使用字根练习和必拆字练习。

## 编码原理

夜莺单字全码写作：

```text
abxy = 双拼音码 ab + 首根 x + 末根 y
```

完整说明见：[首末根原理](docs/principles/首末根原理.md)与[选词原理](docs/principles/选词原理.md)。

字架思路受虎码字架方案启发。夜莺结合自己的根集和规范拆分进行了逐字适配，不将字架概念视为夜莺原创。详见：[0.9字架说明](releases/v0.9/03_字根与拆分/夜莺码v0.9字架说明.txt)。

## 历史版本

0.1—0.7及0.4等已经废弃的方案保存在[`archive/releases`](archive/releases/)。它们用于追溯设计过程，不代表当前夜莺，也不建议新用户安装。

历史版本中仍然有效的设计思想会提炼到`docs/principles`；具体旧键位、旧根集、旧码表和阶段性结论继续留在归档中。

## 当前数据关系

```text

              ↓
         两张正式主表
```
