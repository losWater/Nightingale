# 夜莺 2.5 · Mac

完整包有三个入口：**夜莺2.5·V5**、**夜莺2.5·形码**、**夜莺2.5·单字**。
两版共用夜莺2.5码表、查询、钉选及主动造词数据。
形码指固定码表输入方式，编码仍是夜莺的双拼＋首末根，不是改成虎码编码。

## V5 整句版（强烈推荐）

只建议使用 V5 版本；形码和形码单字版只供有明确专项需求的用户选择。

小鹤双拼连续输入，魔虎 V5 本地模型辅助整句，模型候选标记 V5。
保留固定简码和词序，设置菜单没有魔虎语义等未接入功能。
详细功能、模型来源和依赖说明见 V5-README.md。

## 形码版

不加载模型、不自动造句、不按词频调整固定码序，候选只来自固定表和主动造词。
参考本机虎码的有效设置：

- 空格首选、分号二选、单引号三选、数字选词。
- 最大码长四码，五码顶屏：第四码不自动上屏，第五个编码字母顶出当前候选并开始下一编码。
- 表中原有五至八码入口不再作为形码版连续输入入口；词条可用其他编码或在 V5 版输入。
- 空码到最大码长后由下一键清除，保留合法编码的中间前缀，避免词组输入被提前清空。
- Tab 或 Esc 清屏；减号/等号翻页，左右键移动候选。
- 输入 `[` 或 `]` 调出上一条上屏内容，再按空格重复上屏。
- Ctrl+J 显示/隐藏夜莺字根拆分；Ctrl+O 切换简繁输出。
- Ctrl+句号切换中英文标点。
- 反引号或 ~ 加全拼/小鹤双拼，查拆分和编码；F2（或 Fn+F2）筛核心字。
- Ctrl+数字钉选，Ctrl+Enter 保存主动造词，使用现有夜莺的个人数据。

形码版没有整句、模型、上下文等设置开关。显示简体/繁体指转换开关，
默认关闭转换；正式码表内本身存在的繁体字仍可直接输入。

## 安装

完整包包含三个版本；形码、单字独立包不含模型。单字版按虎码单字习惯配置，使用夜莺普通单字表，详见完整包的 SINGLE-README.md。
把包内 YAML、lua/ 和（完整包中的）yeying25_v5/ 复制到 Rime 用户目录。
更新时保留用户数据和 yeying25_v5/config，不要覆盖自己的配置、学习记录。
参照 default.custom.yaml.example，把两个 schema 加入已有方案列表后重新部署。
squirrel.custom.yaml.example 只给出横排补丁；请合并进已有 style 设置，不要整份覆盖原有皮肤。
切换方案：Control+反引号（或按个人既有快捷键）。

早先「夜莺2.5·Mac」原生整句版退出当前发布入口，本机旧文件和词库仍保留供回退。
本机原有虎码等非夜莺方案保留。
