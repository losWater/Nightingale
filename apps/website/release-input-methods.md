## 输入法包与使用说明

优先推荐使用 Rime 或手心输入法。

请下载下方标注 **20260911** 的新版附件；原有1.0附件作为历史快照保留。

<a id="rime"></a>
### Rime 包（推荐使用）

支持夜莺固定字词、简词和双拼整句输入，简词也可以参与整句。

**新增拆分反查**：输入 `~` 或反引号，再输入全拼或小鹤双拼，例如 `~han`、`~hj`，候选旁显示规范拆分与夜莺编码。主力、轻量、形码均支持；空格或数字选字，Esc 取消。反查不调用整句模型。

**F2 核心字查询**：输入两位双拼或三码后按 **F2**，例如 `yc` → F2，即可翻页查看该读音下的核心字、拆分和编码，不混入词组或扩展字。再按 F2 返回普通候选，Esc 取消。三个方案均支持。

- **主力版（测试）**：使用魔虎 V5 整句模型。不超过36键时使用模型，超过后转为原生整句。模型较大，首次加载需要一定时间；长时间使用的稳定性仍在实测。
- **轻量版（测试）**：不带外部整句模型，保留原生整句和用户词典，适合更在意响应速度与资源占用的用户。
- **形码模式**：按四码定长方式输入，适合习惯形码打法的用户。

当前 Rime 发布包面向 **Windows x64 小狼毫**，已在小狼毫0.17.4环境测试。主力模型引擎为 Windows 专用；macOS 和手机端尚未适配验证，请勿将此包视为跨平台通用包。按各包内《使用说明》安装到 Rime 用户目录，再重新部署。升级前请备份个人设置和用户词典。

### 手心输入法（方便上手）
<a id="palm"></a>

使用小鹤双拼，导入夜莺挂接码表与辅助码，即可配合手心自身的词库和整句输入使用。

- **挂接码表**：通过自定义短语导入，提供夜莺单字、简词及相关固定候选；另有不含普通全码二字词的版本，可按习惯选择。
- **辅助码**：通过手心的辅助码导入入口导入，用于单字筛选；提供 UTF-8 和 Unicode 两种编码，选择一份即可。
- **导入兼容修复**：曲的辅助码保留 `ea en ex` 三组，移除辅助码 `pa`，避免四组辅助码导入卡死。自定义短语中的 `qup/qupa` 兼容入口仍保留。

手心文件位于完整包的 `02_输入法挂接/手心输入法` 目录。请分别使用自定义短语和辅助码的对应导入入口。

### 其他输入法

搜狗等其他输入法的配套包目前功能并不全面，不十分推荐使用，建议优先选择 Rime 或手心。

小胖、多多等输入法的配套会尽快上线。
