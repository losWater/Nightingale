# 夜莺网站

无第三方运行依赖的静态网站，支持移动端、明暗主题与键盘操作。

本地预览：

```powershell
python apps/website/build.py
python -m http.server 8765 --bind 127.0.0.1 --directory .tmp/website-preview
```

浏览器打开 http://127.0.0.1:8765 。构建时从当前维护目录复制六个查询和练习页面，避免维护第二份码表。生成目录位于 `.tmp/website-preview`，不提交。

构建来源为 `releases/v1.0`；作者文章读取 `素材/作者的话.md`。构建依赖 Python Markdown（`pip install Markdown`），浏览器运行无需依赖。

正式网站：https://loswater.github.io/Nightingale/ 。GitHub Pages 使用 gh-pages 分支根目录，发布时上传 `.tmp/website-preview` 的构建结果。Rime 与手心更新包在 v1.0 Release 的 20260911 附件中。

## 字根表改版

按首页主题重做网站字根表，保留两种展示：默认主根版采用键盘上仅主根、下方归并小字表的形式；显示归并版将附属根展示在所属主根旁。两版由现有正式字根HTML中的同一份数据生成，当前174主根、26键，避免维护两套独立数据。支持部件名称与键位搜索，沿用网站明暗主题，提供打印样式。已核对浏览器中174条主根完整、版本切换正常，以及“冓头”搜索定位M键。正式码表未改动。

字根配色调整：主根改为更亮的月白色并加粗，附属根及归并小字表同步提亮；横、竖、撇、折、点五个笔画单独使用金色，两个版本共用标色。浅色与打印模式采用深金色以保持清晰。已在浏览器核对五个笔画标色及普通字根颜色。
