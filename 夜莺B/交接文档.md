## 一、我们在做什么

夜莺码 = 小鹤双拼 + 首末根两位形码（abxy）。v0.4 维护线证明了根表是"从别的方案贪出来的"，不直观。**夜莺B 是按音节重新选根的重生方案**：

1. 音节按常用字数排序（`work/../work/音节排序表.tsv`），逐音节看常用字，挑人认识的偏旁/部件当根，让同音节高频字的首根互不相同。
2. 每条"立根/合并/挂靠"都用两项指标核：**①三简竞争**（先排除每音节唯一的二简字 `ab`，剩余每个首根堆只有一个三码位 `abx`；比较合并前后新增的堆内竞争）**②全码撞**（同音节首末组合相同）。本来就撞的不算合并的账。
3. 每次新增或确认一个根，都要主动检查：**对应的常用部首/偏旁形有没有漏挂，以及还有没有应一起考察的形近变体**。chai 中整字、偏旁和变体常是不同元素，不能因为整字已经成根就假定偏旁会自动生效；候选附属仍须过全字集三码重和全码重。
4. 键位最后交给 chai.exe 退火；根表是退火上游。五大笔画根固定键（横h 竖u 撇p 点d 折v，或五笔式 tyghn，待定），其余自由。

主人的工作风格：**一个一个来，不抢跑，不连珠炮追问**；给完数据就停；表格要放在回复最后（不要夹在工具调用之间，否则被折叠看不到）；语气轻松可带表情。

## 三、脚本用法（都在 `夜莺B/scripts/`，Bash 里 `export PYTHONIOENCODING=utf-8` 后运行）

| 脚本 | 用途 | 例 |
|---|---|---|
| `syl_table.py 音节 [最低频万]` | 音节过堂表：按 B 根集算首/末根，按首根分堆，≥3 标 ⚠，后附结构明细 | `python 夜莺B/scripts/syl_table.py ui 1` |
| `merge_check.py "根1+根2+…" [...]` | 合并/挂靠检查：各根首末用户、排除二简后的新增三码竞争、全码撞。根名可用汉字或 chai 部件名（如 `全字头`、`然左角`） | `python 夜莺B/scripts/merge_check.py "礻+衤" "山+出"` |
| `chai_lookup.py 字或部件名 …` | 查 chai 结构树（递归展开 PUA 部件）、首链/末链、按 B 根集的首末根、作首末部件的用户字 | `python 夜莺B/scripts/chai_lookup.py 鱼 衡 然左角` |
| `b_roots.py [N]` | 按当前根集列出前 N 字里"首末根相同(abxx)且自身不是根"的字；根集不完整时当"缺根探测器"用 | `python 夜莺B/scripts/b_roots.py 3500` |
| `build_workbook.py` | 重生成 `work/音节选根工作表.md`（前40音节×前27字的首位部件链）和 `work/偏旁部首覆盖表.tsv` | |
| 主仓 `scripts/syllable_util.py` | v0.4 的音节简码利用率基线（405 音节 × 27 位） | |

`work/根集.yaml` 是所有 B 脚本的根集输入：`roots: {主根: [附属...]}`，`anchors: {笔画根: [锚定根...]}`。每次裁决后手动改它。

### 用 chai 查一个字 / 用不同拆法查
- 结构：`chai_lookup.py 字`。chai 字库是 `repos/webchai/packages/hanzi-chai/src/data/repertoire.json.deflate`（zlib 压缩 JSON，每条 `{unicode|name, glyphs:[{type: compound|basic_component|derived_component|spliced_component, operator, operandList, strokes, tags}]}`；带 `G` tag 的 glyph 是大陆字形）。PUA 部件靠 `name` 识别（如"益字头""左字框""应字心"）。
- "不同拆法"：chai 只给一种结构树，我们的拆法是自己定的。要试"把某部件当根/不当根"的效果，用 `merge_check.py` 把它和候选宿主一起传入；要试整字拆法（如 来=一米 vs 来整根），照 `选根台账.md` 里"来"那条的做法：分别按两种首末根算同音节的全码同位和三简堆友（可参考会话里那段脚本，逻辑都在 b_roots.py 的 head/tail 上改）。
- 注意 chai 把很多字视为独体（里 本 正 西 面 来 事 业 平…），对它们 `b_roots` 会落到笔画；这类字的拆法得人工定。

## 五、坑
- console 是 GBK：脚本顶部 `sys.stdout=io.TextIOWrapper(sys.stdout.buffer,encoding='utf-8')` 或环境变量 `PYTHONIOENCODING=utf-8`。
- Python 打开文件用 `D:/...`；Git Bash heredoc 会吃 `\uXXXX`/PUA 字符——含 PUA 或转义的内容用 Write/Edit 工具或 `chr(0xE902)`。
- 表格给主人看要放在回复最后；给完数据就停，等主人裁决。
- 台账与根集.yaml 要同步；根集里附属用 chai 的部件名（如 `学无子`、`尚头`、`全字头`）。
