# 夜莺 B 可用布局快照：夕 M、长 J

封存时间：2026-08-25。

这是扩展字词硬约束重退火之前的可恢复基线。来源为正式 12 路退火的 0 号母布局，随后只接受两项经 chai 精确复核的局部移动：`夕 A→M`、`长 B→J`。

核心指标：

- 前 1500 单字全码重码：0
- 前 3500 单字全码重码：21
- 前 6000 单字全码重码：192
- 前 1500 单字简码重码：0；三码 1339
- 前 3500 单字简码重码：3；三码 2637
- 全码组合当量：1.3328
- 简码组合当量：1.3360
- 原硬词撞口径（前 1500 字 × 前 10000 二字词）：0
- 扩展试验口径（第 1501～3500 字 × 前 2000 二字词）：5

文件：

- `config.yaml`：完整布局与目标配置。
- `elements.yaml`：与布局配套的分析元素表。
- `code.txt`：由 chai encode 重新生成的精确码表。
- `metric.txt`：同次 encode 的精确指标。

该快照不得被后续退火输出覆盖。
