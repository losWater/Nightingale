# 夜莺B —— 按音节选根的重生方案（2026-08-23 起）

## 出发点
形码只需要在**同一音节内部**把字区分开。v0.4 的根是从简单鹤/虎码按全局覆盖贪出来的，天然带偏；
夜莺B 改为：按音节排序 → 看每个音节里的常用字 → 直接挑人认识的偏旁部首/直观部件当根，使高频字首根互不相同。
键位排布仍交给退火（chai.exe），根表是退火的上游。

## 数据事实（来自 v0.4 readings，405 音节）
- 常用字（前3500）>27 的音节仅 14 个（yi57 ji52 yu51 ui49 fu/vi/qi41 xi/yj38 jm37 ww36 li30 uu29 xm28），>20 的 29 个
- 三简容量整体够用，问题全在分布（首根撞键）；v0.4 满员音节平均只用 19.5/27 位
- 多重简码永不加（设计哲学）

## 文件
- `work/音节选根工作表.md`：前 40 音节 × 前 27 常用字，每字给结构 + 首位部件链（hanzi-chai）
- `work/偏旁部首覆盖表.tsv`：174 个常见偏旁部首在前 6000 字中的首位/任意位覆盖字数与频率
- `scripts/build_workbook.py`：重生成以上两表
- 主仓 `work/音节排序表.tsv`、`work/音节简码利用率.tsv`、`scripts/syllable_util.py`：音节排序与 v0.4 利用率基线

## 工作流程（拟）
1. 主人逐音节圈根（工作表上直接标）
2. 汇总成根表草案 → 跨音节一致性检查（同一部件同一拆法）→ 统计根数
3. 用根表生成拆分 → chai.exe 退火排键 → 与 v0.4 对标（三码率/选重/当量/音节利用率）
